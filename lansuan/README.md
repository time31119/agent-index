# 澜算 LANSUAN · GPU 算力资产平台

一个面向 GPU 算力整机「采购 → 托管 → 租赁收益」的概念网站，包含产品展示、实时收益测算、托管节点网络、资产台账、合伙人分享机制与可下载的分享海报。

## 快速预览

直接用浏览器打开 `index.html` 即可。页面内的复制、二维码、海报 PNG 导出均已适配本地文件打开。

如需通过 HTTP 访问（推荐用于分享与真实二维码测试）：

```bash
# 任选一种
node .preview-server.mjs
# 或
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 页面模块

- **Hero / 品牌首屏**：产品渲染图、实时节点卡片、月净现金流示例。
- **业务链路**：采购、托管、租赁收益三段式说明，含风险边界。
- **在售机型**：H200、H100、RTX 4090 三款整机，支持按训练 / 推理筛选与资产明细弹窗。
- **收益计算器**：机型、数量、出租率、托管等级实时联动；输出月净现金流、参考年化、静态回本期、5 年曲线、收入拆分。
- **托管网络**：6 个可点击节点，PUE、绿电、时延、剩余机位随选择更新。
- **运营台账**：资产估值、净租金、流水、在线率与风险提示的界面演示。
- **合伙人分享机制**：单层直推、三档奖励、专属链接 / 二维码、海报生成、邀请文案复制。
- **FAQ / 预约表单**：可展开问答、预算选择、前端校验与成功态。
- **分享海报**：Canvas 生成 1080 × 1440 PNG，内置产品图与真实可扫二维码。

## 分享机制口径

- 只做一级直推，不做多层分销。
- 分享官 0.6%、合伙人 1.0%、城市主理人 1.5%。
- 奖励基数为整机采购合同金额（不含税、电费与增项），由平台服务费列支。
- 回款后 T+7 结算。
- 页面中所有收益数据均为情景演示，不构成保本、保收益承诺。

## 修改数据

产品价格、租金、托管费、残值率与节点数据在 `assets/app.js` 顶部的 `PRODUCTS` / `NODES` 对象中。产品卡片上的静态价格与参数在 `index.html` 中，修改时请同步两处。

分享奖励档位在 `openShare()` 的 tier 映射中调整。
