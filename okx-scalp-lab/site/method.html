01 / 数据

数据来自 OKX 公共行情 API 的 /api/v5/market/history-candles，抓取时间为 2026-11-04 15:00 UTC。四个品种：BTC、ETH、SOL、DOGE 的 USDT 本位永续合约（*-USDT-SWAP），30 分钟周期。每个品种 4,320 根 K 线，覆盖 83.7 天；四个品种取时间戳交集后对齐，确保同一根 K 线在所有品种上都能交易。

OHLCV 使用 OKX 返回的已确认 K 线（confirm=1），不使用未收盘的当前 K 线。成交量字段为合约张数，未做币本位换算；策略信号只使用价格与成交量相对变化，不依赖绝对单位。

样本区间：2026-08-12 21:30 → 2026-11-04 15:00 UTC。理论 4,020 根，实际 4,020 根，缺失 0 根。前 300 根用于指标预热（EMA200 / Supertrend 等），有效回测约 83.7 天，不计入收益统计。

01B / 周期实验

为了回答“是不是周期越短越好”，同一批策略、同一段 90 天原始数据，分别在 5m / 15m / 30m / 1h 上重跑。每组使用 200 根预热，四品种等权，成本仍为 6bp/边。

周期最优净收益最优策略正收益数成本拖累 / 中位买入持有
5m25,917 根 · 89.3 天 -20.88% 布林带 + RSI(2) 回踩 0 / 10 62.3 pp +24.57%
15m8,640 根 · 87.9 天 -8.00% 肯特纳挤压突破 0 / 10 32.3 pp +21.65%

结论很直接：5m 上 0/10 为正，15m 上 0/10，30m 上 0/10，到 1h 才有 3/10 转正。这不是指标突然变聪明，而是交易次数下降、成本占比下降。5m 的“灵敏”是用更高的换手买来的。

02 / 执行

  • 信号时点：每根 30m K 线收盘后计算指标与条件。
  • 成交时点：下一根 K 线开盘价成交，不使用当前收盘价，避免未来函数。
  • 仓位：1x 名义本金，只做多或做空，不叠加、不金字塔加仓。组合层面四品种等权，每根 K 线再平衡。
  • 离场：收盘确认的止损/止盈/通道离场；反向信号在下一根开盘直接反手。没有盘中触价成交，因此不会出现“同一根 K 线先止损还是先止盈”的路径歧义。
  • 强平：不模拟。1x 名义本金下，理论上不会被强平；若使用更高杠杆，结果不适用。

03 / 成本

单边成本 0.06bp：OKX 永续 VIP0 taker 手续费 0.05%（5bp）+ 1bp 滑点近似。每次反手按两次成交计费，即 12bp 往返。成本按成交名义金额扣除，直接计入现金。

没有计入：资金费率（8 小时一次，方向随市场变化）、盘口冲击、延迟、滑点随波动率放大、API 限频、强平罚金。对 30 分钟级别策略，这些项目通常会让真实结果比回测更差，而不是更好。

零成本净值只用于诊断“成本拖累”，不是可实现的收益。若一个策略的毛收益很高、扣费后转负，说明它的边际优势不足以覆盖交易摩擦。

04 / 排名口径

主排名使用 四品种等权组合的有效样本净收益（约 84 天）。每个品种独立回测，组合净值按每根 K 线等权平均；不是把四段收益简单相加。这样单一品种的极端行情不会淹没其他品种。

主指标Net Return / 净收益（扣 6bp/边）
辅助指标Profit Factor、Max Drawdown、Sharpe、Win Rate、Trades、Avg Hold
基准四品种等权买入持有，同样扣一次期末平仓成本
年化不展示年化。约 84 天的有效样本年化会放大噪声，容易制造不切实际的预期。
杠杆1x。2x/3x 只是把收益与回撤同比例放大，不改变排名逻辑。

05 / 已知局限

  • 样本只有 90 天数据窗口：覆盖不了一轮完整牛熊，有效回测约 84 天。2026 年 8–11 月的波动结构不代表未来。
  • 只测四个主流品种：没有覆盖小市值 alt，结论不能直接外推到流动性差的合约。
  • 参数是标准值：没有做大规模参数寻优，避免过拟合；但也意味着每个策略都没有被“调到最优”。
  • 没有强制日内平仓：30m 策略的平均持仓约 8–12 小时，部分趋势单会持有过夜。若你要求严格日内，请在 Pine 代码中加入 UTC 会话收盘前平仓。
  • 没有资金费率：长期持仓的策略会被资金费率影响；超短线影响较小，但不是零。
  • 没有盘口与延迟：30m 策略对执行速度敏感，真实滑点可能高于 1bp，尤其是在插针与新闻行情。
  • Pine 代码不是逐行复刻：社区脚本常有隐藏的 repaint、安全函数与默认参数差异；本站代码按页面规则重写，需在 TradingView 中独立验证。

06 / 复现

项目是一个纯静态站点，回测与建站脚本在 scripts/。需要 Python 3 与 numpy / pandas：

  1. python scripts/fetch_data.py — 抓取 OKX 30m K 线到 data/raw/。
  2. python scripts/fetch_extra.py — 抓取最新 ticker / funding（可选）。
  3. python scripts/backtest.py — 生成 data/results.json 与 site/data/lab.js。
  4. python scripts/build_site.py — 生成全部 HTML 页面与 CSV。
  5. 直接双击 site/index.html，或用任意静态服务器指向 site/。

所有页面通过 <script> 加载数据，没有 fetch 依赖，因此 file:// 协议下也能正常显示图表。
