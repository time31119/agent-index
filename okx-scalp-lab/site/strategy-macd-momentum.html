01策略逻辑

MACD 柱状图是快慢均线差的动量导数。柱体在零轴一侧持续放大，说明趋势在加速；翻色代表动量衰竭。

优势 / EDGE. 比单纯 MACD 金叉更早识别动量变化；柱体翻色离场能避免扛单。
风险 / RISK. 震荡市中柱体会频繁翻色，交易次数多；零轴附近信号质量差。

02入场与离场规则

L做多 / LONG

  • MACD 柱 > 0 且较前一根放大
  • 收盘价 > EMA200

S做空 / SHORT

  • MACD 柱 < 0 且较前一根放大（更负）
  • 收盘价 < EMA200

X离场 / EXIT

  • 柱体翻负（多）/ 翻正（空）
  • 收盘价跌破/升破 EMA200
  • 持仓满 24 根

06Pine Script v6 代码

以下代码是本站按上述规则重写的可运行版本，不是对某个 TradingView 社区脚本的逐行复制。默认佣金 0.06%/边、滑点 2 tick、1x 名义本金；把 commission_value 改成你的实际费率后再看结果。

PINE SCRIPT / v6
//@version=6
strategy("MACD Histogram Momentum", overlay=true, initial_capital=10000,
     default_qty_type=strategy.percent_of_equity, default_qty_value=100,
     commission_type=strategy.commission.percent, commission_value=0.06,
     slippage=2, pyramiding=0, calc_on_every_tick=false)

[macdLine, signalLine, hist] = ta.macd(close, 12, 26, 9)
ema200 = ta.ema(close, 200)
barsInTrade = strategy.opentrades > 0 ? bar_index - strategy.opentrades.entry_bar_index(0) : 0

longEntry  = hist > 0 and hist > hist[1] and close > ema200
shortEntry = hist < 0 and hist < hist[1] and close < ema200
longExit   = hist < 0 or close < ema200
shortExit  = hist > 0 or close > ema200

if longEntry
    strategy.entry("Long", strategy.long)
if shortEntry
    strategy.entry("Short", strategy.short)
if longExit or shortExit or barsInTrade >= 24
    strategy.close_all()

plot(macdLine, color=color.aqua)
plot(signalLine, color=color.orange)

07怎么用

  1. 在 TradingView 打开 OKX:BTCUSDT.P 或对应合约的 30 分钟图表。
  2. 打开 Pine 编辑器，新建策略，粘贴上面的代码，保存并添加到图表。
  3. 在「策略测试器」里把佣金设为 0.06%、滑点设为 2 tick，时间范围选最近 90 天。
  4. 先看回撤和交易次数，再看收益。若交易次数 < 20，统计意义很弱；若成本拖累 > 10pp，换手过高。
  5. 实盘前至少做一次样本外验证（例如最近 30 天）和一次参数扰动（±20%），不要只看最优参数。
