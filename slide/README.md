独立品牌 **SLIDE**（SLIDE DESIGN LAB，深圳）的首款概念产品站点。
一句话：把一卷照片，放进口袋。

- 线上页面：`index.html`（产品主页） / `series.html`（系列画册） / `story.html`（设计手记）
- 类型：概念产品 + 品牌官网（预订为前端演示，不发送任何数据）
- 技术：纯静态 HTML / CSS / JS，无构建、无外部依赖、无图片素材

## 2. 产品：SLIDE 01

一台只做一件事的设备：把 12 张照片装进口袋，用拇指一张张翻。

| 项目 | 参数 |
| --- | --- |
| 显示 | 2.9″ 彩色电子纸，480 × 320，48 色，3 秒刷新 |
| 机身 | 6063 铝合金 + 再生 PC，62 × 44 × 9.8 mm，68 g |
| 交互 | 侧面 12 档机械滚轮（霍尔计数），无触摸屏 |
| 连接 | BLE 5.2、NFC (ISO 15693)、USB-C 2.0 |
| 续航 | 320 mAh，约 180 天（每天翻 6 次），静止零功耗 |
| 存储 | 8 MB，本地缓存 12 帧 |
| 面板 | 0.6 mm 阳极氧化铝，磁吸对位，首批五色 |
| 软件 | DARKROOM：裁切 3:2 + 六种抖动胶片预设（SPECTRA / NEWS / BLUEPRINT / SEPIA / NEON / MUD） |

### 三个产品决定

1. **电子纸，不是 LCD** —— 断电后画面还在，产品因此没有「通知入口」的属性。
2. **滚轮，不是触摸** —— 有档位就能盲操作，不必点亮屏幕。
3. **磁吸，不是螺丝** —— 面板可换，让同一个物件保持新鲜。

## 3. 系列 01：四种动作

SLIDE 01 不是单品，而是系列的第一件。整个系列共用一条设计规则：**一个动词，一件物件**——每一件都靠一个机械动作翻页，没有触摸屏，也没有「滑动」。

| 型号 | 动作 | 形态 | 价格 |
| --- | --- | --- | --- |
| **01 WHEEL** | 拨动 | 口袋幻灯机，12 档滚轮 | $69 |
| **02 FLIP** | 翻面 | 双面吊坠：42 mm 316L 圆盘，两片电子纸背对背，IMU 感应翻面 | $129 |
| **03 DRAW** | 抽拉 | 3:2 电子纸卡片 + 阳极氧化铝套筒，4 mm 磁栅分段 | $89 |
| **04 TURN** | 旋转 | 4.7″ 圆屏 + 1.2 kg 铝底座，12 档外圈，整点自动换图（也是钟） | $249 |

- **材质工艺 ED.01**：MIRROR 镜面铬 / ENAMEL 珐琅 / CERAMIC 陶瓷 / ANODIZED 喷砂阳极 / BLAST 玻璃珠喷砂 / PVD 钛彩。每一代只开一种工艺与颜色，卖完再开下一色；页面上点一下，三件新物件一起更换。
  - 所有表面共用一套 CSS「表面配方」：虹彩层（可选）+ 随指针移动的高光 + 拉丝纹理（1px 平行线，密度与粗糙度对应）+ 五段色阶渐变；六种工艺只是参数不同（高光强度、纹理密度、虹彩）。
  - **可交互**：FLIP 点击会真的翻面（CSS 3D + 背面另一张画）；DRAW 悬停抽出一格、点击换图；TURN 点击转动外圈并换页；鼠标在物件上移动时，高光会跟着走。

## 4. 与参考产品的差异

参考对象：ENILINX（ENIAC）的 TICKEY —— 3.7″ 彩色电子纸挂件，靠 App 投图、NFC 分享。
SLIDE 01 借用的是「彩色电子纸 + 随身佩戴 + 零功耗显影」这个品类判断，产品逻辑则另起一条线：

| 维度 | TICKEY | SLIDE 01 |
| --- | --- | --- |
| 形态 | 3.7″ 横向票据/挂件，3.8 mm | 35 mm 幻灯片比例（3:2），带滚轮的 9.8 mm 机身 |
| 翻页 | App 内选择 + 机身按键 | **12 档机械滚轮**，离线即可翻完一整卷 |
| 内容单位 | 单张图 / 轮播 | **一卷 12 张**，本地缓存，不依赖手机 |
| 软件主张 | 编辑器 + 模板 | **DARKROOM 胶片预设**：只决定「脾气」，不修图 |
| 场景 | 包挂 / 电子吧唧 / 胸牌 | 口袋里的相册、桌面立牌、礼物 |
| 情绪 | 时尚配饰、表达 | 安静留存、少看手机 |

## 6. 技术实现

- 无框架、无 CDN、无图片文件；离线双击 `index.html` 即可浏览。
- `assets/js/art.js`：12 个程序化场景（落日、早安、浪、月、名片、天气、色卡、蓝图、小票、诗、地图、夜）+ 6 套调色板 + Bayer 4×4 有序抖动量化 + 分色调曲线（NEWS 提亮、SEPIA 压暗）；`paintCrop()` 负责圆形屏/吊坠的中心方裁。
- `assets/js/app.js`：机身组件（canvas 屏 + 滚轮）、滚轮 `wheel`/拖拽/方向键交互与「显影闪白」动画、胶片条同步、暗房预设、换壳、滚动揭示、移动端菜单、预订表单校验。
- `assets/js/series.js`：02 FLIP / 03 DRAW / 04 TURN 三个物件的 canvas 上屏、翻面 / 抽拉 / 转圈交互，以及 ED.01 材质一键切换。
- `assets/css/series.css`：三个物件的「以 em 缩放」组件（`font-size` 一个值即可整体缩放，从页脚小图到产品大图），以及系列页版式。
- 大尺寸画面以 2× 分辨率渲染后再量化，保证文字边缘干净；机身屏保持 1× 像素感。
- 可访问性：`prefers-reduced-motion` 降级、滚轮 `role="slider"` + 方向键、按钮 `aria-pressed`、表单错误提示。
- 响应式断点：1400 / 1180 / 820 / 620 px；移动端隐藏十字辅助线、物件等比缩放、产品块改为「图在上、文在下」。
