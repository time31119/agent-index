A / IDEMPOTENCY

重复执行是灾难，丢失也不可接受

每条信号写入队列时生成唯一事件 ID。执行端以“事件 ID + 账户”为幂等键，重复消息只会命中已处理记录，不会产生第二笔订单。

B / PRECISION

不足最小下单量，就明确失败

换算结果低于交易所最小单位时不强行下单，标记失败并通知跟随者。部分平仓按相同比例镜像，同时对数量取整，避免长期偏差累积。

C / RECONCILE

每 30 秒，仓位必须对得上

拉取交易员持仓并与跟随者仓位汇总比对。系统性偏差超过 5% 时告警，暂停该信号源的新开仓，等待人工排查。

你的阀门，
