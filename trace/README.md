# 循迹 TRACE — 链上永续合约跟单执行层

一个面向 **Hyperliquid / OKX 信号源** 的加密永续合约跟单平台高保真原型。核心叙事：**跟得快，更要跟得稳**——信号可以来自链上，但执行必须服从跟随者自己的硬风控阀门。

> 本项目是纯前端产品原型。所有余额、仓位、成交、滑点与分润均为演示数据；不连接交易所、不发送订单、不托管资金。

## 页面

- `index.html` — 品牌落地页
  - 首屏执行控制台：信号 → 风控 → 下单的延迟链路
  - 01 信号源：Hyperliquid（P0）、OKX 公开带单（P1）、种子交易员（P2）与硬性准入门槛
  - 02 执行链路：捕获、标准化、队列、换算、风控、执行六段管线
  - 03 风控阀门：滑点、杠杆、日亏熔断、定比/定额的实时换算预览
  - 04 高水位分润：1000 → 1200 → 900 → 1300 的三日结算示例
  - 05 合规边界：地域策略、KYC 与适当性、交易员监控
  - 06 冷启动路线与 07 指标看板
  - 种子名额预约弹窗（前端演示，不发送数据）
- `terminal.html` — 跟单工作台
  - 账户权益曲线（7D / 30D / 90D，支持悬停查看）
  - 跟单仓位、单笔平仓 / 二次确认全部平仓
  - 风控阀门实时计算：日亏剩余额度、保证金占用
  - 模拟信号流与执行日志
  - 高水位分润账本、30 秒对账状态
  - 暂停 / 恢复跟单状态
- `compliance.html` — 合规与边界说明
  - 地域准入预检（前端规则演示）
  - 入金前三道门：KYC、衍生品适当性、风险披露
  - 风险披露折叠面板、交易员监控规则、FAQ

## 本地查看

无需构建、无外部字体或 JS 依赖。直接双击 `index.html` 即可；若浏览器限制本地资源，在目录下启动静态服务器：

```bash
python -m http.server 8000
```

访问 `http://localhost:8000`。

## 交互

- 移动端导航、滚动显现、CST 时钟
- 风控滑点 / 杠杆 / 熔断滑杆，实时更新下单量、名义价值、限价、保证金
- 分润三日结算切换，图表高亮与计费说明联动
- 工作台权益曲线切换与十字准星 tooltip
- 模拟信号入队、执行日志追加、仓位平仓
- 合规页地域 + 投资者类型预检
- `Esc` 关闭弹窗 / 菜单，键盘焦点陷阱与跳至主要内容链接

## 设计

深墨底 + 酸性青柠信号色，等宽数字与细发丝线构成“执行终端”质感；中文大标题使用紧凑字距，避免常见的加密货币霓虹渐变。所有图形与 favicon 均为本地 SVG。
