# 算力地理 · 中国算力中心公开档案

一个可直接打开、无需构建工具的静态网站。按省份整理国家超算、区域超算、智算中心、数据中心与算力园区，记录地址、联系方式、机型、算力、规模、计费口径与资料来源。

当前快照：**64 条设施档案 · 31 个省级行政区 · 11 个国家超算 · 4 个区域超算**。香港、澳门、台湾保留为待补。

## 打开方式

直接双击 `index.html`，或在目录内启动任意静态文件服务器：

```powershell
python -m http.server 8080
# 然后访问 http://127.0.0.1:8080/
```

站点没有外部字体、CDN、图片或后端依赖，离线可用。

## 数据说明

- `assets/data.js` 中的 `CENTERS` 是唯一内容源。新增一条设施，复制一个对象并填写字段即可。
- `confidence` 三档：
  - `official`：地址/电话来自运营方官网；
  - `reported`：来自政府或媒体公开报道；
  - `pending`：只有片区级定位、单一来源或待核实字段。
- `aiCompute` 使用 PFLOPS（通常 FP16），`hpcCompute` 使用 PFLOPS（通常 FP64）。不知道就填 `null`，不要估算。
- `precision` 使用 `门牌` / `园区` / `城市`，它会直接影响详情页的定位提示。
- `pricing` 只记录计费方式与公开价格线索，不编造单价。
- `sources` 优先放运营方官网，其次政府/媒体。页面会逐条展示。

## 维护建议

1. 新增/修订数据后，检查 `id` 唯一、`province` 属于 `REGIONS` 中的 34 个省级行政区。
2. 运行页面，确认筛选、详情、对比与 CSV 导出正常。
3. 每次批量更新后修改 `SITE.snapshot`，并在页脚保留“公开资料、非官方发布”的声明。
4. 如果部署到自己的域名，把 `SITE.maintainerEmail` 填上，并在“补充资料”弹窗中增加邮件入口。

## 已知边界

- 这不是“全国所有算力中心”的官方名录。公开资料无法证明穷尽，站点用“省份覆盖 + 空白字段”显式呈现未知。
- 机房地址、商务电话、在售机型与价格会变化。标注“待核实”的字段，不应作为采购或访问的唯一依据。
- 港澳台当前没有收录设施，省域版图中保留为“待补”。
