# 掌柜 ZHANGGUI

> 你打烊，它开张。

一个参考 Polsia 思路、但针对中文生意场景重新设计的产品概念站：AI 经营合伙人，而非"AI 替你开公司"。
纯静态实现，无构建步骤、无框架、无外部图片与字体依赖。

## 查看

双击 `index.html` 即可。四个页面互相打通：

| 页面 | 文件 | 内容 |
| --- | --- | --- |
| 官网首页 | `index.html` | 夜班机制、六位 Agent、三道闸、商业模式、场景、合规、FAQ |
| 工作台 | `console.html` | 晨报、KPI、14 天趋势图、Agent 运行状态、待确认队列、执行流水 |
| Agent 团队 | `agents.html` | 七环编排、岗位输入输出、交接规则、权限表 |
| 定价 | `pricing.html` | 三档套餐、抽成计算器、三种做法对照、收费 FAQ |

## 可交互的部分

- **待确认队列**：批准 / 驳回 / 全部批准，卡片状态、侧栏角标、顶部 KPI 与提示条会同步更新
- **抽成计算器**：切换套餐、拖动广告消耗与新客成交额，实时算出订阅 + 8% 服务费 + 3% 分成（封顶 ¥3,000）与综合成本率
- **趋势图**：原生 SVG 绘制，双曲线 + 渐变面积，入场描边动画（尊重 `prefers-reduced-motion`）
- **移动端菜单**、FAQ 手风琴、按钮提示条、键盘焦点样式

## 说明

掌柜为虚构概念品牌，与 Polsia 无关联。站内客户、评价、经营数据、价格与备案信息均为演示内容；
「批准」「驳回」只改变前端状态，不会向任何服务器发送数据。

设计与商业模式说明见 [DESIGN.md](DESIGN.md)。
