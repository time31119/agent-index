01 — 岗位说明

每个岗位，
都有明确的输入与输出。

察

市场侦察

Recon

不改价、不投放，只负责把"外面发生了什么"变成一张可决策的表格。它的价值不在于信息多，而在于敢说"这个机会不该做"。

输入
  • 竞品链接 / 类目榜单
  • 评论区与问答
  • 平台搜索词
输出
  • 机会评分表
  • 卖点假设 3 条
  • 价格带建议
选

货品掌柜

Merchandiser

会算账的选品。把进货价、退货率、平台佣金、投放成本一起放进去，算出"卖出去到底赚不赚"，然后劝你砍掉不赚的。

输入
  • 货源与成本
  • 动销与退货数据
  • 竞品价格带
输出
  • 货盘与组合装
  • 定价与毛利模型
  • 滞销清理建议
筑

门面掌柜

Storefront

做的是"三秒看懂"：落地页、详情页、小程序、公众号菜单。所有页面都跑性能预算，不达标就自己重做。

输入
  • 卖点与价格
  • 素材与资质
  • 转化数据
输出
  • 落地页 / 详情页
  • 小程序页面
  • A/B 版本
言

内容掌柜

Voice

不追求"写得好"，追求"测得动"。同一个卖点写三版，让它去撞流量；撞不动的版本，第二天自己换掉。

输入
  • 卖点假设
  • 爆款结构库
  • 历史转化数据
输出
  • 短视频脚本
  • 图文笔记
  • 直播与私域话术
引

投流掌柜

Media Buyer

最像"员工"的一个：每天建计划、关计划、换素材、调出价。所有规则写死在代码里，你可随时查它为什么加了一笔钱。

输入
  • 预算与 ROI 目标
  • 素材与人群包
  • 实时消耗数据
输出
  • 投放计划与出价
  • 素材淘汰结论
  • 预算调整申请
应

跑堂掌柜

Service

客服、催付、售后、复购。它最重要的能力是"知道自己不该答"——退款、投诉、发票、法务，一律带着上下文交回给你。

输入
  • 咨询与订单
  • 物流与售后状态
  • 话术库
输出
  • 首响与解决率
  • 转人工清单
  • 复购唤醒计划

02 — 交接规则

让 AI 干活容易，
让它们不出错很难。

结

结构化交接

每一环只能交出带 schema 的对象：结论、证据、置信度、建议动作。置信度低于 0.6 的结论，不允许触发花钱。

降

失败即降级

抓取失败就退回缓存，素材缺失就沿用旧图并标记，模型超时就缩小批次。任何一环不允许"假装成功"。

忆

共享店铺记忆

你三个月前说过"不做低价"，会写进所有 Agent 的约束；每一次驳回，都会变成下一次的默认规则。

插

随时可接管

任一 Agent 可被单独暂停，任务上下文完整保留。你接手做完，它会从你留下的结果继续往下跑。

03 — 权限表

它能做什么，
写到可以被审计。

动作 默认权限 额度 / 边界 谁批准
修改商品价格 可自主 单次调整不超过 ±8% 超出需你批准
上下架 SKU 可自主 单次不超过 10 个 批量操作需你批准
新建投放计划 可自主 每条日预算 ≤ ¥300 自动执行
调整计划预算 可自主 单次加幅 ≤ 30%，单计划日耗 ≤ ¥900 超限需你批准
对外发布内容 不可 必须过违禁词与标识检查 发布闸人工确认
回复顾客咨询 可自主 不含退款、发票、法律承诺 敏感场景转人工
发起退款 不可 — 仅限人工操作
导出经营数据 可自主 仅限本店，不含消费者个人信息 含个人信息需二次确认

所有动作写入不可篡改的操作日志，包含触发原因、模型版本、审批人。日志保留 12 个月，可导出。

先看它们干一晚，再决定要不要雇。
