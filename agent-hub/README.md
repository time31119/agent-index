## 打开方式

双击 `index.html` 即可，不需要服务器、不需要联网。站内链接指向工作区里的其他项目（相对路径 `../xxx`），`file://` 与本地 HTTP 服务下都能跳转。

## 功能

- **搜索**：名称、英文名、简介、标签、分类、端口号都能命中，多个关键词取交集。
- **分类标签**：顶部胶囊切换，数字由数据自动统计。
- **详情**：点击卡片打开，含完整简介、标签、入口地址、原始地址、端口与启动方式，可复制链接。
- **深链**：`index.html#ai-trader-100u` 直接打开对应站点详情。
- **快捷键**：`/` 聚焦搜索，`Esc` 关闭详情或清空搜索，`Enter` 打开首个结果。

## 维护

站点数据集中在 `app.js` 顶部的 `AGENTS` 数组，每条形如：

```js
{
  id: 'ai-trader-100u', no: 10, cat: 'trading',
  name: '交易终端', en: 'AI TRADER 100U',
  sub: '1000 U 纸上交易终端',
  desc: '……',
  tags: ['Hyperliquid', '纸上交易'],
  href: 'http://127.0.0.1:8777/',
  src: 'http://127.0.0.1:8777/',
  demo: '../ai-trader-100u/static/index.html',
  port: '8777', start: 'ai-trader-100u\run.bat（实时行情版）'
}
```

- `cat` 取值：`trading` / `video` / `atlas` / `product` / `business` / `toolbox`。
- `no` 决定卡片编号，新增条目时顺延；分类计数与标签页自动生成。
- `live` / `demo` 为可选的第二个入口，有值时详情里会多出对应按钮。
- `agents.json` 是导出副本，改完 `app.js` 后可重新导出。

## 说明

- 带 `:3000`、`:8080`、`:8770`、`:8791`、`:8777`、`:8899`、`:8900`、`:8788`、`:8099`、`:4173` 标记的站点需要先启动本地服务，详情里有启动命令；其余为纯静态页面，可直接打开。
- **APEX 默认打开本地静态页** `apex/index.html`；详情里的「实时服务」指向 `http://127.0.0.1:8791/index.html`。
- **NexusGate（`:3000`）直接打开实时服务** `http://127.0.0.1:3000/`；启动命令：在 `nexusgate` 目录运行 `python app.py`。
- **Agent Alpha（`:8080`）默认打开实时服务** `http://127.0.0.1:8080/index.html`；离线可用详情里的「静态入口」。
- **AI Paper Desk（`:8770`）直接打开实时服务** `http://127.0.0.1:8770/`；启动命令：在 `quant-runner` 目录运行 `python -m paper_desk.server --port 8770`。
- **ASTER（`:8787`）使用 `aster/stable/index.html` 静态快照**，模型与统计数据已内置，不依赖本地服务；详情里另有「实时服务」按钮指向 `http://localhost:8787/`。
- **交易终端（`:8777`）直接打开实时服务** `http://127.0.0.1:8777/`；本地服务没启动时，详情里可切到「演示模式（示例数据）」。
- **Whiteboard Studio（`http://localhost/`）直接打开实时服务**；启动命令：进入 `whiteboard-studio` 目录后运行 `python server.py 80`。
- 原 `我的Agent.txt` 中的 `http://127.0.0.1:…` 与 `file:///…` 地址已映射到工作区内的实际入口，详情里保留「原始地址」。
