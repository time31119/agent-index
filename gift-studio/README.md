# 礼序 LIXU · 企业礼品定制所

一个面向企业促销礼赠场景的静态品牌站 + 在线 Logo 预览工作室。

客户只需要上传自己的 Logo，就能在 13 件常用促销品上实时看到效果：换产品、换颜色、调 Logo 大小/角度/位置、切换浅色/深色背景，并下载 1500 × 1500 的 PNG 效果图。

## 快速打开

直接双击 `index.html` 即可使用。所有产品图都是内联 SVG，Logo 只在浏览器本地处理，不需要服务器。

如果希望通过本地地址访问，也可以：

```bash
cd gift-studio
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

建议使用较新的 Chrome、Edge、Safari 或 Firefox。

## 已实现的功能

- **Logo 上传**：PNG / JPG / SVG / WebP，≤ 8MB；支持点击选择和拖拽上传；带示例 Logo，打开即可体验。
- **13 件常用促销品**：帆布袋、马克杯、笔记本、签字笔、桌垫、T 恤、棒球帽、卫衣、折叠伞、双肩包、保温杯、充电宝、皮质钥匙扣。
- **实时预览**：上传后所有产品卡片、组合方案和选品单缩略图同步更新。
- **产品定制**：每个产品独立记忆颜色、Logo 大小、旋转、位置与呈现方式（原色/纯白/单黑）。
- **拖动与键盘微调**：直接拖动画面中的 Logo，或用方向键移动（Shift 加速）；双击 Logo 回到中心。
- **场景切换**：浅色 / 深色预览背景，方便判断深色产品上的 Logo 对比度。
- **图片导出**：Canvas 生成 1500 × 1500 PNG，包含背景与最终 Logo 位置，无客户端水印。
- **选品单**：加入/移除、数量调整、预估合计、导出 CSV。
- **询价表单**：本地校验并生成需求单编号；演示环境只保存在 localStorage，不发送网络请求。
- **组合方案**：入职礼、客户答谢礼、展会礼三套组合，一键载入选品单。
- **选品库**：按办公/穿戴/出行/数码/生活筛选，支持名称、材质、工艺搜索。
- **响应式**：桌面、平板、手机三套布局，移动端支持折叠菜单和全屏选品抽屉。

## 想改内容？

### 品牌色与字体

编辑 `styles.css` 顶部的 `:root`：

```css
--paper: #f2eee5;
--ink: #171915;
--forest: #17382f;
--lime: #d9ed8a;
--coral: #e8623d;
--font-sans: "Manrope", ...;
--font-serif: "Noto Serif SC", ...;
```

字体通过 Google Fonts 加载，断网时会自动回退到系统字体（中文衬线回退到宋体，无衬线回退到苹方/微软雅黑）。

### 增加一款产品

在 `products.js` 里按现有格式新增一项：

```js
{
  id: "bottle",
  name: "运动水壶",
  en: "SPORTS BOTTLE",
  category: "出行",
  price: 58,
  moq: 50,
  size: "600 ml",
  craft: "丝印 / UV 彩印",
  tag: "户外",
  scene: "#d9e0d8",
  print: { x: 500, y: 560, w: 160, h: 160 }, // 1000 × 1000 画布坐标
  baseRotation: 0,
  colors: [{ name: "奶白", body: "#e8e2d5", dark: "#cfc7b8", light: "#faf6ed", detail: "#9b907f" }],
  art: bottleArt, // 返回 1000 × 1000 的内联 SVG
}
```

`print` 是 Logo 可以占据的矩形区域（中心点 + 宽高），会同时用于屏幕预览与 PNG 导出。SVG 内部请使用唯一的 gradient / filter id，避免多实例冲突；现有模板都用 `nextUid()` 生成前缀。

### 修改产品文案与价格

所有产品的名称、英文名、分类、参考价、起订量、工艺、描述都在 `products.js` 的 `PRODUCTS` 数组里，改完刷新页面即可。

### 接入真实询价

当前 `app.js` 的 `submitQuote()` 只把需求单写进 localStorage。正式上线时，把这里替换为你的接口即可：

```js
await fetch("/api/inquiries", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(order),
});
```

然后移除页面上“演示站点”的说明文案。

## 设计说明

- **视觉方向**：纸张米色 + 深森林绿 + 荧光黄绿 + 陶土橙，偏编辑型品牌站，而不是常见的电商模板。
- **产品图**：全部为手绘 SVG “studio mockup”，不依赖外部图片，所以打开快、可无限缩放、可以精确对齐 Logo。
- **版式**：大字号中文衬线标题、细线网格、编号式章节（01–06），让礼品站更像一本选品手册。
- **交互**：工作室是页面核心，左侧控制、右侧大图；产品卡片和组合方案都可以直接载入同一套 Logo。

## 演示口径

- 页面中的客户名称、电话、地址、价格、交期均为示意，不构成真实报价或合作背书。
- 询价提交不会发送到服务器，只在浏览器本机生成需求单。
- 产品效果图基于模板生成，实际印刷效果需以打样为准。

## 已验证

- 桌面 1440 × 1000、平板 1024 × 900、手机 390 × 844 三档布局。
- 无 JavaScript 运行错误；无横向溢出。
- SVG Logo 上传后跨产品同步。
- 拖动 Logo、浅色/深色导出、1500 × 1500 PNG、CSV 导出、选品单与成功状态均已通过无头浏览器测试。
