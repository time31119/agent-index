# LeadScope · 币安合约带单透视

一个独立的静态站点：抓取币安 USDT-M 合约带单员（Copy Trading）的收益、回撤与逐笔结构，
回答「榜单前十名值不值得跟」，并给出一套可执行的判断工具。

- 打开方式：双击 `index.html`（纯静态，无需服务器、无需联网）。
- 数据快照：2026-11-05 00:25（UTC+8），样本 931 位带单员。

## 结论（TL;DR）

| 观察 | 数值 |
| --- | --- |
| 30 天收益前十名中「前 60 天」为负 | 8 / 10（中位 −72%） |
| 前十名中历史最大回撤 ≥75% | 6 / 10（中位 −78%） |
| 前十名中全期收益仍为负 | 4 / 10 |
| 30 天收益与前 60 天收益的秩相关 | −0.03（无预测力） |
| 全样本 30 天收益中位数 | +0.25%（51.7% 为正） |
| 全样本全期收益为负 / 夏普为负 | 47.5% / 52.1% |

**判断：** 按 ROI 榜单跟单没有正期望；前十名绝大多数是「大亏之后的杠杆回本 + 幸存者偏差」。
有价值的是它们的风控结构学习价值，以及那份「先算损耗、再谈收益」的判断流程。

## 数据与复现

数据来自 Meror 对 Binance Copy Trading 的公开镜像（`sourceId=binance_copy`）。
币安官方页面受 Cloudflare 挑战与登录态限制，直连 `/bapi/copy-trading/*` 返回 403。

```bash
python data/fetch.py        # 多排序键并集抓取 → raw_binance.json
python data/build_data.py   # 清洗 + 统计 → leadscope/assets/data.js
```

刷新数据只需替换 `assets/data.js`，页面无需改动。

## 口径与局限（摘要）

- 跟踪期最长 90 天，不足以覆盖完整牛熊；「前 60 天」由全期与 30 天收益反推。
- 只包含存活组合，爆仓/关闭的组合不在样本内 → 结论偏乐观而非偏悲观。
- 覆盖率 931 / 2,114（合格样本 44%）；平均盈亏口径由镜像方定义，未披露计算方式。
- 缺少「跟单人实际 PnL」字段，跟单损耗在模拟器中近似。
- 本项目仅供研究，不构成投资建议。合约与跟单交易可能导致本金全部损失。

## 可跟单指数

0–100，权重偏向风险与延续性而非收益：

| 分项 | 权重 | 规则 |
| --- | --- | --- |
| 生存（回撤） | 30 | `30 × e^(−|回撤|/22)` |
| 延续性 | 20 | 前 60 天与 7 天都为正 = 20；一个为正 = 8 |
| 风险调整收益 | 20 | `30天收益/(回撤+8)`，回撤 >50% 打 0.45 折、>70% 打 0.2 折 |
| 收益结构 | 15 | 正偏满分；小赢大亏（盈亏比<0.45 且胜率>72%）得 2 分 |
| 成本/频率 | 8 | ≤60 笔/月满分；>500 笔整体 ×0.65 |
| 记录长度 | 7 | ≥180 天 7 分，≥90 天 5 分 |

阈值：≥65 可小额试跟，45–65 观察，<45 不建议。931 位中分别占 6.9% / 27.2% / 65.9%。
