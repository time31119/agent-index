      FAQ
      
常见问题

    

    

      

        和直接申请官方 API 有什么区别？
        
官方要海外卡、要外币结算、要自己处理网络，而且每个厂商一个后台。我们把这些收在一层里：账单和发票是人民币的，协议是统一的，出了问题只有一个地方找。

      

      

        为什么比某些站贵？
        
因为那些站便宜在「共享会员账号」，官方一封号就断，余额也退不回来。我们的供给是采购和自部署，成本压不到那个程度，但能开票、能签 SLA、不会一夜消失。

      

      

        我的代码和对话会被看到吗？
        
默认不记录内容，只记金额和 token 数。企业客户可以把整套部署在自己机房，数据不出域。

      

      

        余额能退吗？会过期吗？
        
不会过期。未消费部分可按原路退回，只扣支付通道已经产生的手续费。企业客户也可申请后付费与月结。

      

      

        支持哪些客户端？
        
兼容 OpenAI 协议的工具（LangChain、LlamaIndex、Cursor、各类桌面客户端）和兼容 Anthropic 协议的工具（Claude Code、Claude 桌面版）都能直接接入，文档里有逐项配置步骤。

      

      

        令牌分组怎么选？
        
先用「标准分组」验证链路，生产按场景切换：编码场景选「编程分组」，要求稳定选「高可用分组」，已有上游密钥选 BYOK。不确定就选 Auto。
