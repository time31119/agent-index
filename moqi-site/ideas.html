00 / THE FILE READ THIS BEFORE THE FEATURES

先定不做什么，
再谈做什么。

录音卡这个品类有一个天然矛盾：它越无感，越容易冒犯；它越智能，越像监控。所有差异化都必须先回答同一个问题——坐在你对面的人，为什么愿意让它存在？

01 / CORE

共识录音协议

AI 录音硬件的真正门槛不是麦克风，是让坐在对面的人不觉得自己被算计。

核心差异化信任层硬件 + 软件
INSIGHT / 洞察

行业普遍用提示灯、提示音解决“告知”，但告知不等于同意。胸牌形态尤其带有“制服感”，更容易让对方不敢拒绝。真正的同意需要动作、记录和反悔机制。

HOW / 做法

双人按键、NFC 轻触、语音同意三种确认；e-ink 公开显示 2/2；同意台账记录谁、何时、以何种方式确认；24 小时内可撤回；公共场合提供“可见记录”模式。

MOAT / 护城河

不是技术，是信任品牌与双向网络效应。每一次回执都在告诉对方：“这个设备是可以被拒绝的。”这份体面本身成为购买理由。

RISK / 风险

社交尴尬、不同司法辖区的同意规则、恶意绕过。产品必须默认“可见记录”，并允许被记录方一键撤回，而不是把责任推给用户。

“同意不是一个开关，是一个动作。”

SCORECARDRELATIVE
差异化5
可行性4
护城河5
成本友好3

评分是相对值，不是结论。真正重要的是：它是否让“被记录的人”也愿意推荐产品。

02 / CORE

对话回执

录音让人不安，是因为价值只归记录者。回执让对方也得到一份可用的东西。

核心差异化产品格式双人价值
INSIGHT / 洞察

会议纪要只对记录者有用。被记录的人得到的往往是一段不知道会不会被断章取义的音频。价值不对称，是录音设备被排斥的根本原因。

HOW / 做法

30 秒内生成决定、承诺、下一步；NFC 碰一碰或链接分享；事实部分双方共享，私密备注各自保留；24 小时内可撤回；纸质回执可作为品牌物料。

MOAT / 护城河

回执是一个可以被识别的产品格式。当对方开始期待“会后那张回执”，默契就不再是一个录音设备，而是一种协作习惯。

RISK / 风险

摘要错误会直接摧毁信任；回执不应被宣传为具有法律效力；对方可能仍不愿意被记录。需要把“不生成”也设计成一个体面的结果。

“让对方也有收获，是最好的隐私策略。”

SCORECARDRELATIVE
差异化5
可行性5
护城河5
成本友好4

最值得先做的功能。用手机 + 人工回执就能验证，不需要等硬件。

03 / CORE

关系记忆

用户不想管理文件，只想在下次见面时接得上。记忆的单位不是录音，是人、项目和承诺。

核心差异化数据模型长期留存
INSIGHT / 洞察

录音软件按日期和文件管理内容，但人脑按关系和未完成的事管理记忆。下次见一个人之前，你想知道的是“上次我们聊到哪”，不是“10 月 28 日的第 3 段录音”。

HOW / 做法

人物页、项目页、承诺页三套视图；会前 3 分钟 brief；承诺自动提醒；同一段对话可以同时属于一个人、一个项目和一个未完成事项；按人和项目设置可见范围。

MOAT / 护城河

数据网络效应与切换成本。用得越久，关系图谱越难迁移。但前提是数据可导出、可删除，否则护城河会变成 distrust。

RISK / 风险

冷启动时没有足够数据；错误关联会让人尴尬；把人际关系做成 CRM 容易显得功利。产品语言要避免“客户资产化”。

“不是记住更多，而是下次见面时接得上。”

SCORECARDRELATIVE
差异化4
可行性3
护城河5
成本友好3

不要一上来做完整 CRM。先做“见面前 3 分钟”的单一场景。

04 / CORE

本地记忆库

云端默认是行业惯性，不是用户选择。对医生、律师、记者，本地不是卖点，是采购前提。

核心差异化隐私架构B2B 门票
INSIGHT / 洞察

大多数 AI 硬件的商业模型依赖云端订阅，因此“默认上云”被包装成体验优势。但高敏感场景的用户，愿意为“不上云”付溢价。

HOW / 做法

端侧 ASR 与摘要、AES-256 本地存储、安全芯片、物理麦克风遮片、30 天默认保留、可选私有云、随时导出；云端同步逐项授权，不做“一键全开”。

MOAT / 护城河

不是模型能力，是架构选择与信任品牌。竞品可以加一个“本地模式”，但很难放弃以云为中心的收入模型。

RISK / 风险

端侧模型质量、功耗、散热与成本；离线体验如果明显差于云端，用户仍会打开云。需要接受“本地是 80 分，而不是 100 分”。

“不上云，不是功能，是默认值。”

SCORECARDRELATIVE
差异化4
可行性3
护城河4
成本友好2

这是最贵的一条，也是最难被抄的一条。先从“本地保存 + 云端可选”做起，不必第一代全离线。

05 / EXPANSION

情境卡 DECK

用户不知道怎么“配置”一个录音卡。实体卡比 App 菜单更直觉，也更有仪式感。

产品扩展实体生态礼品属性
INSIGHT / 洞察

录音卡的设置藏在 App 里，用户不会用。把“今天要做什么”变成一张放在桌上的卡，既降低学习成本，也让录音这件事有一个开始的动作。

HOW / 做法

NFC 情境卡：谈判、采访、门诊、课堂、灵感、婚礼。每张卡定义输出模板、保留期、共享规则和提醒方式。可做联名、限量、自定义印刷。

MOAT / 护城河

物理生态 + 礼品属性 + 品牌触点。单张卡复制成本很低，但“卡 + 模板 + 品牌”的组合不容易抄。

RISK / 风险

用户不愿多带几张卡；丢失后无法切换；场景教育成本高。第一代只送 3 张，不单独卖整套。

“把场景放在桌上，而不是藏在设置里。”

SCORECARDRELATIVE
差异化4
可行性5
护城河3
成本友好4

最适合做众筹赠品和品牌联名的功能。先验证“用户会不会真的带出门”。

06 / EXPANSION

记忆保质期

记忆的价值在于遗忘，不是无限堆积。默认永久保存，是产品经理的懒惰。

产品扩展隐私默认品牌承诺
INSIGHT / 洞察

所有记录类产品都在增加存储，很少有人帮用户删除。结果不是“记得更多”，而是“找不到重要的”。遗忘应该是一种默认能力，而不是隐藏设置。

HOW / 做法

默认保留 30 天；重要记忆手动升级为永久；会后 24 小时提示“要留下吗”；支持“会后即焚”；保留期仪表盘；删除有 7 天冷静期，但可一键彻底删除。

MOAT / 护城河

品牌承诺与合规优势。当竞品还在用“永久保存”做卖点时，默契可以把“敢删”做成信任资产。

RISK / 风险

误删、用户焦虑、恢复机制复杂。需要极其清晰的提示，以及“重要记忆”一键升级，不能让用户觉得设备会擅自丢东西。

“不重要的记忆，应该自己走开。”

SCORECARDRELATIVE
差异化4
可行性5
护城河3
成本友好5

软件层就能做，适合作为第一批固件的默认设置。它会让一部分用户不舒服，但会赢得另一部分人的信任。

07 / EXPANSION

静默界面

可穿戴设备最大的失败，是要求注意力。录音卡不该有屏幕争夺你的眼睛。

产品扩展工业设计设计原则
INSIGHT / 洞察

智能硬件习惯用屏幕、灯效、震动和语音证明自己“在工作”。但在对话现场，任何多余的光和声音都在打断关系。安静不是缺陷，是高级感。

HOW / 做法

e-ink 常显、单键操作、触觉反馈、无扬声器、无发光；只在被看时显示状态；录音开始/结束用一次极短的触觉，不用提示音。

MOAT / 护城河

工业设计与克制。功能容易被抄，但“少做一点”的品牌一致性很难被以增长为导向的团队坚持。

RISK / 风险

反馈不足、盲操作、学习成本。需要用极清晰的物理布局和一次性的 onboarding 来补偿。

“最好的界面，是对方几乎感觉不到它在工作。”

SCORECARDRELATIVE
差异化3
可行性5
护城河2
成本友好4

这不是一个功能，而是一条设计宪法。所有新功能都要先问：它会不会让卡更吵？

08 / EXPANSION

反助手

所有硬件都在做 AI 助手，但用户不需要另一个会说话的设备。默契不回答你，只替你记得。

品牌立场品类定位反共识
INSIGHT / 洞察

“助手”意味着随时待命、主动介入、替你决策。但在真实对话里，最体面的角色是记录者，不是参与者。用户不需要一个插嘴的 AI。

HOW / 做法

没有聊天框、没有主动建议、没有 always-on 唤醒；只做 capture、structure、recall 三件事；所有 AI 输出都以“回执/摘要”形式出现，不以对话形式出现。

MOAT / 护城河

在“助手”噪音中形成清晰反差。品牌一句话就能被记住：“它不回答你，只替你记得。”

RISK / 风险

投资人可能觉得想象力小；用户可能期待聊天；媒体难以一句话解释“没有助手”的价值。需要用场景而非功能来沟通。

“不插嘴，是一种高级的智能。”

SCORECARDRELATIVE
差异化5
可行性5
护城河3
成本友好5

这是品牌定位，不是功能。它决定了我们不做什么，也决定了我们如何拒绝“加一个聊天框”的诱惑。

09 / MOAT

记忆公证

高风险对话需要的不只是摘要，而是可验证的事实。有些话，需要被证明发生过。

长期护城河B2B法律与医疗
INSIGHT / 洞察

律师、医生、HR 和高管面对的不是“记不住”，而是“说不清”。一段可编辑的摘要无法作为事实依据，但一条带时间戳和同意记录的哈希可以。

HOW / 做法

本地哈希 + 可信时间戳 + 同意台账 + 不可篡改的版本链；导出证据包；与律所、公证机构、电子签名服务合作；默认关闭，仅在明确场景开启。

MOAT / 护城河

合规集成与高切换成本。一旦进入法律/医疗工作流，替换成本远高于消费级录音卡。

RISK / 风险

法律有效性因地区而异；安全责任重大；销售周期长。不能把它宣传成“自动具备法律效力”。

“不是所有记忆都需要公证，但有些记忆不能只有你说过。”

SCORECARDRELATIVE
差异化5
可行性2
护城河5
成本友好1

第二年再做。先以“可导出的同意记录”作为最小版本，不承诺法律效力。

10 / MOAT

团队记忆层

组织失忆比个人失忆更贵。人走了，承诺还在，但没人知道。

长期护城河B2B基础设施
INSIGHT / 洞察

咨询、律所、投资机构的核心资产是“谁在什么情况下答应了什么”。这些信息散落在个人录音、微信、邮件和离职员工的脑子里。

HOW / 做法

共享记忆库、角色权限、保留策略、同意台账、SSO、审计导出、私有化部署；按项目交接而不是按录音共享；员工离职时可移交“承诺”，不可移交私密对话。

MOAT / 护城河

企业工作流与合规。从工具变成基础设施后，替换成本极高。

RISK / 风险

隐私文化冲突、部署成本、与会议软件/CRM 竞争。必须坚持“同意优先”，否则会变成员工监控工具。

“团队记忆不是监控，是交接。”

SCORECARDRELATIVE
差异化4
可行性3
护城河5
成本友好2

先找 2 家律所/咨询公司做付费试点，不要一上来做通用企业版。

11 / MOAT

卡片工坊

AI 硬件很少成为“物件”。证件卡天然适合被携带、被赠送、被收藏。

品牌实验情感价值联名
INSIGHT / 洞察

录音卡是少数可以“被看见”的 AI 硬件。它别在胸前，出现在桌面，被递给对方。它不只是工具，也是一张名片、一份礼物、一个身份表达。

HOW / 做法

定制印刷姓名、团队、婚礼日期、毕业年份；艺术家联名；限量编号；企业周年礼盒；与独立书店、咖啡馆、设计酒店做场景联名。

MOAT / 护城河

品牌与情感。功能可以被抄，但“我想拥有它”很难被抄。它也是获客成本最低的礼品渠道。

RISK / 风险

小众、库存、交付周期、定制化毛利低。先做 100 张内部邀请制，不开放大规模定制。

“让记忆有一个可触摸的封面。”

SCORECARDRELATIVE
差异化3
可行性4
护城河2
成本友好3

不是第一优先级，但很适合做发布会、媒体礼盒和种子用户身份标识。

五件我们坚决不做的事。

× 01

不做 always-on

没有持续监听，没有“随时待命”。记录必须从一个明确动作开始。

× 02

不做云端默认

不会把“方便”包装成“必须”。本地模式不是阉割版，是完整产品。

× 03

不卖数据

不出售、不交换、不“匿名化后共享”。这条没有例外，也没有“合作方例外”。

× 04

不做情感陪伴

不拟人、不卖萌、不制造依赖。它不是朋友，是一张可靠的卡。

× 05

不做万能助手

不替你回邮件、不替你决策、不主动插嘴。克制是产品的一部分。

90 天，验证三件事。

在开模之前，先用纸、手机和人工服务验证需求。硬件不是第一步，信任才是。

W1—W2

20 场真实对话

用纸卡原型测试“双方确认”动作。记录对方是否拒绝、是否尴尬、是否要求删除。

W3—W4

10 场人工回执

手机录音 + 人工整理，24 小时内给对方一张回执。观察对方是否使用、是否转发。

W5—W8

50 张回执

测试分享率、撤回率、二次使用率。重点不是“觉得好用”，而是“下次还愿不愿意让对方录”。

W9—W12

EVT + 2 个 B2B 试点

完成工程样机，找 2 家律所/咨询公司做付费试点。验证团队版是否真的有人买单。

GO / NO-GO10 个用户，4 周后仍有 6 个在用；50% 以上的回执被分享；至少 3 个用户主动要求给同事买。若对方在体验后仍普遍感到被冒犯，暂停。若回执分享率低于 20%，说明“双人价值”不成立。

差异化不是加功能，
是敢少做一点。

如果这份档案里只能先做一件事：做对话回执。它能用手机验证，也能立刻让对面的人感到不同。
