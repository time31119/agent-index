01 / CORE

先有分寸，
再谈智能。

大多数 AI 硬件的品牌故事是“更强、更快、更懂你”。默契的故事相反：更少、更慢、更知道什么时候不该出现。这不是功能差异，是品牌的世界观。

POSITIONING / 定位

给靠对话吃饭的人，一张先征得同意、再开始记录的记忆卡。

不是通用 AI 助手，不是录音笔，也不是会议软件的硬件壳。它属于那些每天用对话推进事情的人。

PROMISE / 承诺

记得住，也懂分寸。

“记得住”是能力，“懂分寸”是选择。前者让你愿意用，后者让坐在你对面的人愿意继续聊。

BELIEF / 信念

记忆是一种关系，不是一次采集。

记忆包含同意、语境、归属和遗忘的权利。把它当作数据抓取，产品就会走向偷听；把它当作关系，产品才知道边界在哪。

AUDIENCE / 人群

咨询顾问、创始人、律师、医生、记者、研究者。

他们不缺少录音工具，缺少的是一份能在下一次对话前 3 分钟看完、并且敢给对方看的记忆。

02 / NAME

默契，
一个安静的约定。

中文名先于英文名存在。它不是“Silent Agreement”的翻译，也不是“AI Recorder”的包装。它是一个先于产品存在的日常词：默，是不喧哗；契，是彼此的约定。

默

不喧哗

不主动打断，不要求注意力，不把“智能”变成一种噪音。它安静地待在那里，直到你需要它。

契

约定，也是刻下

古人把约定刻在木上，称之为契。记录不是抓取，是把彼此都认过的事，认真地留下来。

间

在两个人之间

默契不是一个人对另一个人的读取，是两个人之间已经存在的理解。产品只是把它保存得更久一点。

PRONUNCIATION / 读法

mò qì。第二个字不读“qiè”。英文写作 MOQI，全部大写，不写成 MoQi 或 Moqi。

NAMING RULE / 用法

中文优先。品牌自称“默契”，产品称“默契 CARD 01”，公司称“默契实验室 / MOQI LAB”。不要把“AI 录音卡”放进品牌名。

商标与查重说明：“默契”是一个常用中文词，显著性有限，需在第 9 类（电子设备）、第 35 类（广告与商业）和第 42 类（软件与技术服务）进行检索与注册评估。英文“MOQI”在部分类别可能已有相同或近似商标。本页为品牌概念提案，不构成商标可用性结论。正式发布前，应完成中国、美国、欧盟及目标市场的查重。
03 / MARK

两句话之间，
留一个点。

标志由两道相向的弧线和一个圆点组成。弧线是两个人、两段声波、一次对话的两端；圆点是那段值得被留下的东西。它不是一个“录音”符号，而是一个“之间”的符号。

01 / 最小尺寸

标志不小于 24 × 24 px；完整组合不小于 96 px 宽。小于这个尺寸时，只使用标志，不使用英文全称。

02 / 安全边距

以中心圆点的直径为单位（1×）。四周至少留出 1× 的空白，不与其他图形、文字或图片边缘相切。

03 / 背景

优先使用纸白或墨黑纯色底。红色标志只放在纸白上；深底使用反白组合。不要在复杂照片、渐变或高饱和色块上直接使用。

04 / 不要这样

不要拉伸、旋转、描边、加投影、改弧度、把圆点换成其他图形，也不要把“默契”拆成两个独立的字标。

04 / COLOR

纸、墨、
一枚印章。

色彩不追求“科技蓝”。它来自桌面：纸白是背景，墨黑是文字和机身，印章红只出现在需要被确认的地方，黄铜是按键和边缘的一点温度。红色是动词，不是装饰。

USAGE / 用色比例

70% 纸白、20% 墨黑、8% 印章红、2% 黄铜。红色只用于行动、确认、警示和品牌印记，不用于大面积背景。深色版面不超过整体的一半。

ACCESSIBILITY / 对比度

正文使用墨黑 on 纸白，对比度 ≥ 7:1。红色文字只用于 18 px 以上的标题或短标签；正文中的红色需要加粗或放大。不要用红色承载大段说明。

05 / TYPE

像一封信，
也像一份技术图纸。

中文标题用宋体，正文用黑体，数据用等宽字体，英文点缀用旧式衬线斜体。四种角色，四种语气：被认真写下的、被清楚说明的、被精确记录的、被轻轻说出的。

01 / DISPLAY

Noto Serif SC 600 / 700。字距收紧（-0.04em ~ -0.06em），用于大标题和品牌宣言。不要用 900 字重堆压迫感。

02 / BODY

Noto Sans SC 300 / 400。行高 1.8 ~ 2.0。正文颜色用墨黑或 70% 墨，不用纯黑，也不用浅灰到读不清。

03 / DATA

IBM Plex Mono 400 / 500。全部大写，字距 0.08em ~ 0.16em。用于编号、参数、同意状态、回执字段。

04 / ACCENT

Cormorant Garamond Italic。只用于英文短句、引语和品牌尾注。不要用它排中文，也不要整段使用。

06 / GRAPHIC

把“同意”
做成可以看见的纸。

品牌的图形语言来自三种纸：回执、档案、印章。细线、编号、虚线、裁切标记、条形码和红色圆章，构成一套“可以拿在手里”的视觉系统。

01 / RECEIPT

回执

一切输出都像一张可以递给对方的纸：有编号、有日期、有双方确认，也有可撕下的边。

02 / SEAL

印章

红色圆章只用于“已确认”“已生成”“已撤回”三个状态。它代表一个动作完成，不是装饰。

03 / ARCHIVE

档案线

细线分隔信息层级，编号标记顺序。像一份被认真归档的卷宗，而不是一张被算法生成的摘要。

DO / 可以

用细线组织信息；用编号建立秩序；用红色圆章标记确认；用裁切标记表达“这是一份被制作出来的文件”；留出足够的空白。

DON'T / 不要

不要用霓虹渐变、玻璃拟态、3D 光球或“AI 大脑”插画；不要把回执做成真正的财务票据；不要让红色印章出现在没有确认动作的地方。

07 / IMAGE

桌面，而不是
太空舱。

影像不追求“未来感”。它发生在有窗的会议室、被磨旧的木桌、摊开的笔记本和一杯凉掉的茶旁边。产品是安静的物件，不是主角。

LIGHT / 光线

侧逆光、窗光、暖白 3200–4500K。允许阴影和纸张的纹理。不要用彩色轮廓光、烟雾或镜面反射制造“科技感”。

OBJECT / 物件

产品永远出现在关系里：被递出去、被别在胸前、被放在桌上、被对方轻触。不要单独悬浮在黑色背景里。

08 / VOICE

礼貌，
但不客套。

我们说话像一个靠谱的同事：先承认边界，再给出结论；用动词，不用形容词堆砌；不承诺“绝对安全”，也不把用户当成需要被教育的对象。

原则这样说不这样说
先承认边界“双方确认”是默认模式，不是唯一模式。绝对安全，永不泄露。
动词优先先确认，再记录。一键记录所有对话。
少即是多一张对话回执。颠覆会议的 AI 超级大脑。
不拟人化它不回答你，只替你记得。你的全能 AI 助理，懂你所想。
把对方当大人你可以随时撤回这次记录。别担心，我们比你更懂隐私。

TONE / 语气

克制、准确、有一点旧派的礼貌。可以幽默，但不油腻；可以坚定，但不居高临下。永远不制造恐惧来卖产品。

MICROCOPY / 微文案

按钮用动词：加入首批、查看回执、撤回记录。状态用事实：等待对方、双方已确认、已生成回执。错误提示给出下一步，不指责用户。

09 / APPLICATIONS

让品牌
落在手上。

从一张卡、一个信封、一张回执开始。包装不做“科技产品盒”，而做一个像档案袋一样可以留下来的物件。开箱不是仪式感，是第一次“被认真对待”。

01 / PRODUCT
CARD 01

宣纸白机身，朱砂共识键，黄铜边缘。正面是 e-ink，背面是记忆凭证。

02 / PACKAGING
档案袋

像一份需要签收的文件袋。打开后是卡、夹、线和三张情境卡。

03 / RECEIPT
回执

纸质回执的视觉语言，搬到屏幕和打印件上。双方各一份，可撤回。

04 / DIGITAL
网站与 App

纸白底、细线、编号、朱砂红。没有渐变球，没有“AI 感”光效。
