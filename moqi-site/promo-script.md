# 默契 MOQI · 品牌故事片 / 投放版

> 记得住，也懂分寸。

这是一支**没有旁白、靠文字与声音讲故事**的品牌片。  
它不解释参数，只讲一个每个人都经历过的瞬间：话说完，就消失了；但有些话，第二天会决定一件事。

### 15 秒版剪辑原则

- 前 3 秒必须让观众看到“损失”：一句话消失了。
- 第 3 秒才出现产品，且产品第一个动作是“确认”，不是“录音”。
- 第 7 秒给出产品差异：`双方确认，才开始`。
- 最后 4 秒只留品牌与承诺，不放参数、不放价格。
- 全程无口播；静音也成立。

## 视觉规则

- **底色**：夜墨 `#11120F` / 纸白 `#F4EFE4` / 印章红 `#C8402C`
- **字体**：Noto Serif SC 做大标题；Noto Sans SC 做说明；IBM Plex Mono 做编号、时间、状态
- **构图**：大量留白，文字居中；卡片始终是唯一主角

- **品牌落款**：每帧右下角留 `MOQI.STUDIO`，左上角留段落编号

## 技术说明

- 成片页：`film.html`
- 渲染：Canvas 2D 逐帧绘制，预览与导出共用同一套绘制逻辑
- 导出：`canvas.captureStream(30)` + 合成音轨 + `MediaRecorder`
- 浏览器：Chrome / Edge 最佳；若浏览器支持 `video/mp4`，直接导出 MP4，否则导出 WebM
- 导出时**保持页面在前台**，不要切换标签页或锁屏；实时录制，48 秒成片需要约 48 秒
- 如需 MP4 且浏览器只给 WebM，可用 ffmpeg 转码：

```bash
ffmpeg -i moqi-film-48s-9x16.webm \
  -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p \
  -c:a aac -b:a 192k \
  moqi-film-48s-9x16.mp4
```

## 投放建议

1. **官网首屏**：用 16:9 版做静音自动循环，配“声音开启”按钮。
2. **视频号 / 小红书**：9:16 版，封面用第 06 段回执特写，标题写“你答应过什么？”。
3. **抖音 / Reels**：15 秒版，前 3 秒黑底白字，第 3 秒产品出现；不要加口播，让字幕承担叙事。
4. **发布会**：48 秒 16:9 版，放到“共识录音”功能之前，先建立情绪，再讲参数。
5. **B2B 销售**：把 48 秒版发给律师 / 咨询顾问，附一句“这不是录音笔，是一张双方都愿意留下的回执。”
