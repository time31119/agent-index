# 默契 MOQI — 共识式 AI 记忆卡

> 记得住，也懂分寸。

一张证件大小的 AI 记忆卡。**先征得同意，再开始记录**；把一段对话整理成决定、承诺和下一步，并给双方一张回执。

这不是又一个「更薄的录音卡」。它重新定义了录音卡的信任模型、输出物和关系数据结构。

---

## 先看结论：四个核心差异化

| # | 差异化 | 一句话 | 为什么难被抄 |
|---|---|---|---|
| 01 | **共识录音协议** | 双方各按一次共识键，e-ink 公开显示 2/2，24 小时内可撤回。 | 不是技术，是品牌信任与双向网络效应。 |
| 02 | **对话回执** | 不给「会议纪要」，给双方一张决定 / 承诺 / 下一步的回执。 | 让对方也有价值，才消除录音恐惧；回执会成为产品格式。 |
| 03 | **关系记忆** | 不按文件管理，按人、项目、承诺管理。下次见面 3 分钟接得上。 | 数据网络效应与切换成本。 |
| 04 | **本地记忆库** | 端侧转写、物理遮片、默认 30 天、云端可选、不训练模型。 | 架构选择与信任品牌；云端收入模型很难跟随。 |

完整 11 个方向、评分、反路线图和 90 天验证计划见 `ideas.html`。

## 怎么打开

直接双击 `index.html` 即可。没有构建步骤，没有依赖。

若浏览器限制本地文件或字体加载，建议在 `moqi-site/` 目录启动任意静态服务器：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

字体通过 Google Fonts 加载（Noto Serif SC / Noto Sans SC / IBM Plex Mono / Cormorant Garamond）。离线时回退到系统宋体 / 黑体 / 等宽字体。

## 可交互的部分

1. **共识录音演示**：点击卡片上的「共识」键，或下方「模拟一次共识录音」。第一次点击 = 1/2 等待对方；约 1 秒后自动进入 2/2 记录状态；再次点击结束并生成回执。
2. **卡片翻转**：点击「翻到背面」，查看记忆凭证、材质与序列号。
3. **3D 倾斜与光泽**：桌面端鼠标移动到卡片上，卡片会随指针轻微倾斜。
4. **关系记忆 tabs**：人物 / 项目 / 承诺三套视图。
5. **人群 tabs**：咨询顾问、创始人、律师、医生、记者、研究者。
6. **定价切换**：记忆库 Plus 月付 / 年付。
7. **预约表单**：校验姓名、邮箱与联系授权；数据只写入浏览器 `localStorage`（键名 `moqi_waitlist_v1`），不上传服务器。
8. **品牌色复制**：品牌页点击色值即可复制 HEX。
9. **移动端导航**：1080px 以下折叠为菜单。

## 品牌故事片 / 推广素材

打开 `film.html`：

- **48 秒品牌故事片**：从“有些话，说完就消失了”到“记得住，也懂分寸”，8 个镜头。
- **15 秒投放版**：信息流四拍，先给损失，再给产品，再给差异，最后只留品牌。
- **9:16 / 16:9**：同一套画面引擎，竖屏投放、横屏官网都能用。
- **一键导出**：Canvas 逐帧绘制 + Web Audio 合成音轨 + MediaRecorder。预览与导出共用同一套绘制逻辑。
- **无版权声音**：铺底、脉冲、纸声、按键、盖章、钟声全部实时合成。
- **无旁白**：画面内字幕叙事，静音信息流也能完整看懂。

导出时请保持页面在前台。Chrome / Edge 若支持 `video/mp4` 会直接导出 MP4，否则导出 WebM；WebM 可用 ffmpeg 转 MP4。完整分镜与旁白稿见 `promo-script.md`。若 `file://` 下浏览器限制录制，在 `moqi-site/` 运行 `python -m http.server 8000`，打开 `http://localhost:8000/film.html`。

**当前限制**：本机 `pwsh` 返回 `0xC0000142`，无法在命令行调用 ffmpeg 预渲染 MP4；因此成片采用浏览器内实时渲染导出，而不是预生成文件。需要无人值守的 MP4 时，可在浏览器导出 WebM 后用 ffmpeg 转码，或把这套 `film.js` 的绘制逻辑接到服务端 Canvas/Remotion。

## 产品概念一页纸

- **形态**：85.6 × 54 × 3.2 mm，28 g，证件卡 / 胸牌 / 口袋。
- **交互**：一个共识键，一块 e-ink，无扬声器、无发光屏、无聊天框。
- **能力**：双 MEMS 阵列、2.3" e-ink、端侧转写、决定 / 承诺 / 下一步提取、NFC 回执。
- **隐私**：物理遮片、AES-256、安全芯片、30 天默认保留、胁迫 PIN、不训练模型。
- **价格**：¥1,099；首批 Founding 500：¥899；本地模式永久免费；云端 Plus ¥19/月或 ¥168/年。
- **人群**：咨询顾问、创始人、律师、医生、记者、研究者——靠对话推进事情的人。

## 一些设计取舍

- **没有使用照片**：全部视觉由 CSS / SVG 构成，保证离线可用、加载快、风格统一。真正拍摄时，建议遵循品牌页的「桌面，而不是太空舱」原则。
- **没有做「AI 助手」界面**：这是品牌立场，不是遗漏。产品只做 capture / structure / recall。
- **没有伪造客户 logo 或真实用户评价**：人群页使用「角色原型 + 合成引语」，并在页面中明确标注。
- **参数是目标值**：页面已标注 EVT 工程验证中，不构成预售承诺。
- **表单是前端原型**：只写 localStorage，不发送任何数据。

## 建议的下一步

1. **先做对话回执，不要先做硬件。** 用手机录音 + 人工整理，找 20 场真实会议，验证对方是否愿意接收、是否使用、是否转发。
2. **用纸卡测试共识动作。** 不做电路，只做一张写着「请轻触确认」的纸卡，观察对方的表情和反应。
3. **找 2 家律所 / 咨询公司做付费试点。** 验证「团队记忆层」是否真的有人买单，而不是创业者自嗨。
4. **再决定是否开模。** Go 标准：10 个用户 4 周后仍有 6 个在用；50% 以上回执被分享；至少 3 个用户主动要求给同事买。
