01 / WHY THE MISSING MEMORY

我们记住了会议，
却记不住答应过什么。

市面上的 AI 录音卡，把一切都录下来，再交给云端总结。听起来很聪明，却漏掉了三件更重要的事：同意、分寸，以及一段对话真正的重量。

01 / CAPTURE✕

录到了，
不等于记住了。

转写越来越长，决定越来越难找。真正需要的是 3 个决定、2 个承诺、1 个下一步，而不是 8,000 字。

02 / CLOUD✕

云端很聪明，
但不一定体面。

不是每段对话都该被上传、索引、训练。记忆需要边界，尤其在它涉及别人的时候。

03 / ALWAYS-ON✕

always-on，
是对在场者的不礼貌。

一个没有明确状态、没有同意仪式的录音设备，会让每个坐在你对面的人，先学会防备。

WHY A CARD, NOT A PIN

卡，是一个
已经被理解的社交物件。

挂件是“戴在自己身上的设备”，卡是“可以被别人看见、递出、翻面的东西”。证件卡的形态，让同意、身份和边界都变得可见。

01 / VISIBLE

可被看见的身份

胸牌天然属于“可以被看”的物件。卡面状态不是藏在 App 里的开关，而是所有人都能读到的公开信息。

02 / HANDED OVER

可被递出的边界

卡可以放在桌上、递给对方、翻到背面。同意是一个动作，不是一段需要滚动的条款。

03 / KEPT

可被留下的物件

不是一次性电子产品。可以印刷、赠送、编号，成为一段关系或一个团队的封面。

05 / MEMORY MEMORY, ORGANIZED BY PEOPLE

不是文件夹，
是关系。

大多数录音软件按日期和文件管理记忆。默契按人、按项目、按承诺管理。下次见面之前，你不需要重听 42 分钟，只需要看一眼：上次你们聊到哪，你答应过什么。

  • 01人物页：每次见面、每个承诺、每个未解的问题。
  • 02项目页：把所有相关对话串成一条时间线。
  • 03承诺页：你欠别人的，别人欠你的，一目了然。
  • 04边界：不同的人、不同的项目，不同的可见范围。

记忆不是更多，而是更准。也不是永远，而是该留下的时候留下。

隐私设计

“本地优先”不是一句营销词，而是一串具体的工程选择：物理开关、端侧模型、加密芯片、默认过期、可撤回。每一个都能被验证。

  • PHYSICAL SHUTTER / 物理遮片滑上即断，不是软件开关。
  • ON-DEVICE ASR / 端侧转写离线可用，不上传原始音频。
  • SECURE ELEMENT / 安全芯片卡丢了，记忆也打不开。
  • 30-DAY RETENTION / 默认保留不重要的记忆，自动过期。
  • DURESS PIN / 胁迫密码在压力下打开一个干净的假记忆库。
  • NO TRAINING / 不训练你的对话，不会成为模型的养料。
我们不会用你的对话
训练模型。

这句话写进产品，不写在隐私政策的脚注里。我们不出售、不交换、不“匿名化后共享”任何一段对话。记忆是人的，不是原材料的。
