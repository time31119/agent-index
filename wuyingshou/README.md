# 无影手 V7.55 · 交易回测与模拟交易终端

一个**纯静态、零依赖**的单页网站，完整呈现 XAUUSDc（现货黄金）的逐笔回测数据，并内置一个持续运行的模拟交易引擎。

直接用浏览器打开 `index.html` 即可（`file://` 可用），也可以放在任意静态服务器上。

---

## 数据来自哪里

来自 `无影手免费公测版.rar` —— 一个 MetaTrader 4 终端数据目录（`11\`）。站内全部行情都由归档里的二进制历史文件解析而来：

| 文件 | 周期 | 根数 | 区间（UTC） |
|---|---|---|---|
| `XAUUSDc1.hst` | M1 | 2066 | 2026-11-09 → 2026-11-10 |
| `XAUUSDc5.hst` | M5 | 2048 | 2026-10-30 → 2026-11-10 |
| `XAUUSDc15.hst` | M15 | 2064 | 2026-10-09 → 2026-11-10 |
| `XAUUSDc60.hst` | H1 | 2064 | 2026-07-07 → 2026-11-10 |
| `XAUUSDc240.hst` | H4 | 2048 | 2025-07-31 → 2026-11-10 |
| `XAUUSDc1440.hst` | D1 | 2048 | 2020-04-12 → 2026-11-10 |
| `XAUUSDc10080.hst` | W1 | 481 | 2017-08-27 → 2026-11-08 |
| `XAUUSDc43200.hst` | MN1 | 111 | 2017-09-01 → 2026-11-01 |

HST 格式：148 字节文件头（版本 401、品种、周期、小数位），随后每根 K 线 60 字节
（8 字节时间戳 + 4 个 double 的 OHLC + tick 成交量）。解析后全部 K 线通过校验：
0 根越界（`high < max(open,close)`）、0 根时间乱序、0 根零值。

> **重要**：归档里**没有**厂商的回测报告（无 `.htm` 报表），原 EA 是加密的 `.ex4`，无法反编译。
> 因此站内的交易记录是**按公开参数体系重建的两套规则**在真实行情上的运行结果，不等于原 EA 的真实表现。

## 重建的两套规则

**趋势引擎 A**（趋势跟随）
- 日线收盘 > EMA50 且 EMA50 抬升 → 只做多；反之只做空
- H1 收盘 > EMA50 > EMA200 结构确认
- M15 上 3 根内收盘重新站上 EMA21，RSI(14) > 52，MACD 柱体上行，EMA21 > EMA55
- 止损 1.8×ATR(14)，盈利 1R 后移保本，之后用 2.5×ATR 移动止损，最长持仓 120 根

**回归引擎 B**（均值回归）
- 收盘跌破布林下轨(20, 2σ) 且 RSI ≤ 30 → 做多；上破上轨且 RSI ≥ 70 → 做空
- 目标为中轨（SMA20，按信号当根锁定），止损 2.2×ATR(14)，最长 48 根，平仓后 3 根冷却

两套均为**文献常用默认参数，未针对本样本调参**。

## 结论（如实呈现）

样本内 2026-10-09 → 2026-11-03（1603 根 M15，约 16 个交易日）：

| 策略 | 净利 | 笔数 | 胜率 | 盈亏比 | PF | 最大回撤 |
|---|---|---|---|---|---|---|
| 趋势引擎 A | −143.26 | 24 | 37.5% | 1.37 | 0.82 | 4.36% |
| 回归引擎 B | −28.97 | 11 | 36.4% | 1.65 | 0.94 | 2.86% |
| 组合 50/50 | −83.76 | 35 | 37.1% | 1.46 | 0.86 | 1.63% |

样本外 2026-11-03 → 2026-11-10（461 根）三者的方向一致，仍为负。

**没有取得正期望。** 参数敏感性表说明了原因：把止损从 1.8 放宽到 2.2×ATR，
趋势引擎就从 −143 变成 +98 ~ +329。一格之差即翻转，说明样本内不存在稳健优势，
只是拟合了这段「震荡下行 + 急反弹」的行情。样本仅 16 个交易日、35 笔交易，
统计上远不足以支撑任何结论。

## 模拟交易

页面加载后自动从**样本外区间**（2026-11-03 11:45）逐根回放，用与回测**完全相同**的规则下单：

- 指标自第一根 K 线递推，保证与回测状态一致（不是"半路起算"）
- 每笔按权益 0.75% 风险反推手数，点差 0.20 美元，进场取下一根开盘价 ± 半个点差
- 真实数据用尽后进入**合成延伸行情**（种子固定的随机游走），用于持续观察规则行为，
  页面上明确标注，不代表真实市场
- 切换策略会自动重建会话并继续运行

## 复现管线

```bash
# 1. 从 RAR 解出 MT4 数据目录（7-Zip）
7z x 无影手免费公测版.rar -o_extract

# 2. 解析 .hst → 回测 → 导出 JSON
python tools/engine3.py      # 回测 + 样本内/外 + 组合
python tools/build_data.py   # 参数敏感性 + data/*.js

# 3. 校验：JS 引擎与 Python 引擎逐笔一致性
node tools/verify_sim.cjs    # in-sample: 24 笔 −143.28 vs −143.26；11 笔 −28.95 vs −28.97
node tools/test_paper.cjs    # 模拟会话端到端 + 账务恒等式
```

`verify_sim.cjs` 的输出证明两套独立实现（Python / JavaScript）在同一区间给出相同交易，
差异仅在分位四舍五入。样本外趋势引擎同样逐分一致（2 笔，−132.05）。

## 已知局限
