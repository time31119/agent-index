# Mosaic 万象 · AI App Studio

> 把一句话，变成能上架的 App。  
> 一个整合「顶尖模型矩阵 + Mobbin 级真实设计库 + 原生 App 交付流水线」的产品规划与可交互原型。

---

## 这是什么

这不是一张空泛的脑图，而是一套可以直接拿去讨论、拆解和开发的产品方案：

- **一份完整的产品规划**：定位、用户、竞品、核心流程、信息架构、对象模型、技术架构、商业模式、路线图、指标与风险。
- **一份多模型编排设计**：2026 年 11 月的模型矩阵、任务路由算法、降级策略、成本模型与评估体系。
- **一套设计系统**：品牌、色彩、字体、间距、组件、动效、可访问性与交付检查清单。
- **一个可交互的高保真原型**：工作台 / 工作室 / 设计库 / 模型矩阵 / 发布，五个完整视图。
- **一个营销官网**：定位叙事、能力展示、设计库、模型矩阵、定价与 CTA。

## 快速打开

直接双击或在浏览器打开：

```
prototype/landing.html    营销官网（建议先看这个）
prototype/index.html      产品原型（工作台 → 工作室 → 设计库 → 模型 → 发布）
prototype/palettes.html   五套配色方向并排对比
```

原型是纯静态 HTML / CSS / JS，无构建步骤、无外部依赖、可离线运行。

### 建议体验路径

1. 打开 `landing.html`，看整体定位与视觉气质。
2. 点右上角「打开工作室」进入 `index.html`。
3. 在工作台输入一句话，点「生成首屏」，看它如何切到工作室。
4. 切到「设计库」，点任意界面看详情抽屉，再点「应用到我的 App」。
5. 切到「模型」，关掉自动路由，感受「可解释的模型选择」。
6. 切到「发布」，看构建流水线与 App Store 预览。
7. 顶栏 `Aa` 可切换高对比模式（纯白底、深墨字、更强边界），用于低对比度屏幕。
8. 想看其他配色，打开 [配色方向](prototype/palettes.html)，五套方案并排对比。

### 快捷键

- `⌘K` / `Ctrl+K`：命令面板
- `Esc`：关闭面板 / 抽屉
- 工作台输入框内 `⌘↵`：生成

## 核心判断

### 1. 单一模型套壳没有未来

2026 年 11 月的第一梯队是一组各有短板的模型：Gemini 4 Carbon 综合领先但受限，Claude Opus 5.5 稳定，Fable 5 在复杂编码上最强但贵且有出口限制，GPT-6.1 Sol 性价比高，DeepSeek V4.1 把高频迭代打到极低成本。

**产品能力不是「接入了哪个模型」，而是「每个任务是否交给了最合适的模型，并且成本可控」。**

### 2. 设计参考不是灵感墙，是约束系统

Mobbin 已经证明：Agent 会写代码，但不知道什么已经奏效。Mosaic 把真实界面拆成布局、组件、token 与动效，在生成前作为硬约束注入，生成后再做 Design Lint。

**从「看起来像」到「在你的场景里有效」，才是差异化。**

### 3. 移动端原生交付是时间窗口

Web 生成器已经很卷，原生 App 涉及 Expo、推送、相机、健康、支付、签名、商店审核。链路又脏又长，反而更难被通用模型直接吞掉。

**先做脏活，建立交付壁垒。**

### 4. 不锁定，是信任的来源

生成的工程是干净的 Expo + TypeScript，`npx expo start` 就能跑。用户随时可以离开，反而更愿意开始。

## 五个视图

### 工作台

- 一句话输入 + 模型 Auto 路由 + credits 预估
- 最近项目、可运行模板、Agent 动态、设计雷达
- 核心动作：90 秒生成 3 页，而不是等 10 分钟生成 30 页

### 工作室

三栏结构，对应三种心智：

- **左：结构**（页面 / 流程 / App Graph）
- **中：结果**（真机画布、组件选中、流程胶片）
- **右：意图**（Agent 对话、设计参考、Design DNA、检查器）

这是 Mosaic 与聊天式生成器最大的界面差异：用户永远同时看到「结构、结果、意图」。

### 设计库

- 612,480 个真实界面的检索叙事
- 平台 / 界面类型筛选 + 自然语言搜索
- 每个界面可展开为「可复用模式 + Design DNA 摘要」
- 「应用」不是复制图片，而是把布局与 token 注入当前项目

### 模型矩阵

- 任务路由表：主模型 / 备用 / 策略
- 成本构成与节省金额
- 质量阈值、自动路由开关
- 8 家供应商、12 个模型的角色说明

### 发布

- 设计冻结 → 代码生成 → 测试 → 构建 → TestFlight → 审核
- 构建日志、产物、上架检查清单
- 自动生成的 App Store 预览与审核备注

## 设计语言

- **最终配色（2026-11-06 锁定）**：暖纸白 `#F1EFE7` + 墨黑 `#0A0A09` + 酸性青柠 `#D5F23F`。青柠只做小面积信号（< 5%），模型品牌色只以 6px 圆点出现。
- **v1.1 可读性增强**：纸白加深、正文升到 15px、metadata 最低 9.5px、边框与深色画布文字同步加强。默认即高对比，不依赖用户开「大字模式」。
- **v1.2 明暗节奏**：工作台主输入区与首个数据卡改为墨黑底，和 landing 的深色视觉一致；不是每个卡片都白，一屏最多一个墨黑锚点。
- **真实界面是唯一的彩色**，工具 chrome 退到纸的质感里。
- **等宽字承担 metadata**：模型名、成本、时间、路由策略。
- **发丝线 + 轻微投影**建立层次，圆角克制，动效 180–240ms。
- **中文优先**，但保留 Prompt / Token / TestFlight 等术语原样。

详见 [`docs/design-system.md`](docs/design-system.md)。

## 重要说明

### 关于模型信息

文档与原型中的模型名称、价格、榜单数据基于 **2026 年 11 月** 的公开信息（Requesty、Artificial Analysis、DeepSeek API Docs、Teamday 等）。模型迭代极快，产品应将模型注册表做成**可热更新的配置**，而不是硬编码。

原型里的成本、延迟、会话占比是**演示数据**，用于表达产品逻辑，不是实际测量。

### 关于 Mobbin

原型中的「612,480 个界面」「Powered by Mobbin」「来自 Mobbin 设计库」是产品概念表达。真实上线前必须：

1. 与 Mobbin 签订 API / MCP 商业授权；
2. 只存元数据与缩略图，不缓存原图、不重建原始界面；
3. 明确归属与退出机制；
4. 未经授权不将参考数据用于模型训练。

如果无法达成合作，Plan B 是自建 5–10 万条人工策展的高信号界面库。这一点在产品规划中有详细讨论。

### 关于 App Store

AI 生成 App 仍需满足 App Store 审核指南（尤其是 4.2 最低功能、5.1.1 权限与隐私）。原型中的「提交审核」是流程演示，真实产品必须内置合规检查与人工确认。

5. 验证付费点：$19 / $29 / $49 三档价格测试，确认「上架」是否比「生成」更强。

## 技术说明（原型）

- 纯静态，无构建、无 CDN、无外部字体依赖。
- 迷你界面使用 **CSS 容器查询（cqw）**，同一套 DOM 可在 42px 缩略图、200px 卡片和 380px 详情中保持一致比例。
- 设计库数据在 `app.js` 的 `refs` 数组中，新增一条即可扩展。
- 所有交互为原生 JS，无框架。
- 支持 `prefers-reduced-motion`。
