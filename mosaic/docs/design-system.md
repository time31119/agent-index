# Mosaic Design System · v1

> 设计目标：让界面像一本安静的product杂志——内容（真实的 App 界面）是唯一的彩色，工具本身退到纸的质感里。

---

## 1. 品牌

### 1.1 名字

**Mosaic / 万象**

- Mosaic：不同模型、不同设计模式、不同代码片段，拼成一个完整的 App。
- 万象：所有模型、所有参考、所有可能，收束成一个成品。
- 英文用于产品与国际化，中文用于品牌叙事：「万象归一，一句话成一个 App。」

### 1.2 标志

- 3×3 圆角方块网格，右上角一块偏移 1px 并填充青柠色。
- 最小尺寸：24px；小于 32px 时去掉偏移，仅保留网格。
- 安全区：标志高度的 0.5 倍。
- 禁止：渐变描边、投影、旋转、把方块换成 App 图标。

### 1.3 语气

- **克制、具体、有判断。** 不说「赋能」「颠覆」「一键改变世界」。
- 文案示例：
  - ✅「先做 3 页，90 秒后在手机上看。」
  - ✅「这个付费墙参考了 12 个同品类产品。」
  - ❌「AI 魔法，无限可能。」

### 2.3 模型品牌色（只做 6px 圆点 / 小标签）

| 模型 | 色值 |
|---|---|

**规则**：品牌色不得用于大面积背景；不得同时出现超过 4 个模型色；模型色永远不替代强调色。

### 2.4 对比度

- 正文 `--ink` on `--paper`：约 **17:1**。
- `--muted` on `--paper`：约 **7.4:1**，可用于 11px 以上的辅助信息。
- `--muted-2` on `--paper`：约 **5.6:1**，只用于 ≥ 9.5px 的 metadata，不用于正文。
- 深色画布 `--canvas-ink` on `--canvas`：约 **17:1**；`--canvas-muted` 约 **8.2:1**。
- 青柠底上只用 `--ink`，不用白字。
- 1px 分隔线使用 `--line`，在纸白上保持可见；不要用 `#EEE` 这类几乎消失的灰。

### 2.5 可读性基线（v1.1）

> 这版专门解决「浅色屏上看不清小字」的问题。默认即满足，不依赖用户开启高对比模式。

1. **正文**：中文 14–15px，英文 14px；行高 1.55–1.7。
2. **功能标签 / 按钮**：≥ 12px；不得出现 10px 以下的可点击文字。
3. **metadata**：≥ 9.5px；只承载次要信息，不承载关键操作或价格。
4. **手机 mock 内文字**：≥ 8px；仅用于展示，不承担真实交互。
5. **正文对比度**：目标 7:1，最低 4.5:1；`--muted-2` 只用于非关键 metadata。
6. **不要用颜色单独传达状态**：配合图标、文字或位置。
7. **在 1440×900、100% 缩放下检查**；同时确认 200% 浏览器缩放不破版。
8. **深色画布上的小字**使用 `--canvas-muted`，不要用 `#777`。
9. **浅色卡片必须有边界**：发丝线 + 1px 轻微阴影，不能只靠背景色差。
10. **禁止**：8px 正文、10px 价格、浅灰底上的浅灰字、透明度低于 0.6 的关键信息。
11. **双保险**：支持 `prefers-contrast: more`；顶栏 `Aa` 可手动切换纯白底 / 深墨字的高对比模式，用于低质量屏幕、强光环境或老年用户。

### 2.6 配色决策与备选

> **最终决策（2026-11-06）：01 暖纸青柠。** 保留其「温和纸底 + 墨黑工具感 + 一点酸性信号」的辨识度；其余四套作为备选存档，不进入默认设计系统。

五套方向都保留「中性底 + 单一强调色 + 高对比文字」的结构：

| 方向 | 纸底 / 卡面 | 强调色 | 气质 | 更适合 |
|---|---|---|---|---|
| **暖纸青柠（已选定）** | `#F1EFE7` / `#FFF` | `#D5F23F` | 编辑、独立、设计驱动 | 独立开发者、创意工具 |
| 冷瓷钴蓝（备选） | `#F2F5F8` / `#FFF` | `#1F4BFF` | 精密、可信、工程感 | 工程团队、B2B SaaS |
| 骨白酒红（备选） | `#F3EDE3` / `#FFFBF4` | `#8E2F2A` | 高端、人文、印刷品 | agency、品牌设计 |
| 石墨橙（备选） | `#101214` / `#171A1D` | `#FF5A1F` | 专业、高能、夜间 | 开发者工具、AI 编程 |
| 雾白松绿（备选） | `#EEF1EA` / `#FFF` | `#2F5D46` | 自然、平静、可持续 | 健康、习惯、教育 |

完整并排预览（含每套的对比度与预览界面）：[`prototype/palettes.html`](../prototype/palettes.html)。

**青柠使用规则：**

1. **面积 < 5%**：只出现在主按钮、进度、选中态、AI 活性点，不做大块背景。
2. **青柠底只用墨黑字**，不用白字；小面积文字用 `--lime-deep`，不直接用荧光青柠。
3. **需要更强的视觉重量时，加墨黑块，不要加青柠面积**。v1.2 的工作台输入区就是按这个规则做的。
4. **不要和第二个强调色并用**；模型品牌色只做 6px 圆点，不算强调色。
5. **深色画布上**青柠可以稍微放大使用，但仍不超过画面的 8%。

**通用规则**：无论选哪套，强调色面积 < 5%；不改变 2.4 / 2.5 的对比度与字号基线；品牌色只做小面积信号，不做大块背景。

## 3. 字体

### 3.1 家族

```css
--font-sans: "Inter Tight", "Geist", -apple-system, "Segoe UI Variable Display",
             "Segoe UI", "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif;
--font-mono: "SFMono-Regular", "JetBrains Mono", "Cascadia Code", Consolas, monospace;
```

- 英文 display 优先 Inter Tight / Geist；中文回退 PingFang / HarmonyOS Sans。
- 等宽只用于：标签、数字、模型名、快捷键、代码、时间戳。

### 3.2 字阶

| Token | 字号 / 行高 / 字重 / 字距 | 用途 |
|---|---|---|
| `display-xl` | 56 / 1.02 / 500 / -0.045em | 营销页主标题 |
| `display-l` | 40 / 1.05 / 500 / -0.04em | 页面标题 |
| `display-m` | 28 / 1.12 / 500 / -0.035em | 区块标题 |
| `title` | 20 / 1.25 / 550 / -0.02em | 卡片标题 |
| `body` | 15 / 1.6 / 400 / 0 | 正文 |
| `body-s` | 14 / 1.55 / 400 / 0 | 次级正文 |
| `label` | 12.5 / 1.3 / 500 / 0.01em | 表单标签、按钮 |
| `micro` | 11.5 / 1.35 / 500 / 0.02em | metadata |
| `mono` | 11 / 1.4 / 500 / 0.04em | 等宽标签 |

**中文注意**：display 字号下中文不要用负字距超过 -0.02em，否则字形挤在一起；中文标题优先 600 字重。

## 4. 间距与网格

- 基准单位：4px。
- 常用：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 / 80。
- 页面左右边距：桌面 40px，宽屏 64px；内容最大宽度 1440px。
- 卡片内边距：16（紧凑）/ 20（默认）/ 24（宽松）。
- 区块垂直间距：营销页 96–120px；产品页 24–32px。
- 12 栏网格，gutter 24px。

### 圆角

| Token | 值 | 用途 |
|---|---|---|
| `--r-xs` | 6 | 标签、小按钮 |
| `--r-sm` | 10 | 输入框、次级按钮 |
| `--r-md` | 14 | 按钮、卡片 |
| `--r-lg` | 20 | 大卡片、面板 |
| `--r-xl` | 28 | 弹层、底部抽屉 |
| `--r-phone` | 44 | 手机外框 |

### 阴影

- 默认用 **1px 发丝线 + 极轻投影**：`0 1px 2px rgba(10,10,9,.06)`。目的不是装饰，而是让白卡从深一档的纸底上「浮」起来。
- 浮层：`0 12px 40px rgba(10,10,9,.14), 0 2px 8px rgba(10,10,9,.08)`。
- 深色画布上的手机：`0 40px 80px rgba(0,0,0,.45)`。

## 5. 组件

### 5.1 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| Primary | 墨黑底、纸白字、`--r-md`、高 40 | 每个视图仅 1 个 |
| Accent | 青柠底、墨黑字 | 「生成」「应用」等 AI 动作 |
| Secondary | 白底、发丝线 | 次级操作 |
| Ghost | 透明、hover 浅底 | 工具栏、图标按钮 |
| Danger | 珊瑚文字/边框 | 删除、断开集成 |

- 高度：36（紧凑）/ 40（默认）/ 48（营销 CTA）。
- 图标按钮：32×32，圆角 8。
- 禁用态：opacity .4，不用灰色替换颜色。
- 按压：`scale(.98)`，120ms。

### 5.2 输入

- 高度 40；圆角 10；边框 `--line-strong`；focus 时 2px `--ink`（不是蓝色）。
- 多行输入：最小 3 行，随内容增长，最大 200px。
- 工作台主输入区可用 **墨黑底反白**作为页面锚点：输入文字 ≥16px，placeholder 用 `#A8A8A0`，focus 边框用青柠。它比普通表单更重，因为它是整个产品的起点。
- placeholder 用 `--muted`，不使用斜体。
- 错误：珊瑚色边框 + 12px 说明，不只用颜色，还要有图标。

### 5.3 标签 / Chip

- 高 26；圆角全圆；1px 发丝线；11px 等宽大写。
- 选中：墨黑底、纸白字；或青柠底、墨黑字（AI 相关）。
- 可关闭 chip 右侧带 ×，点击区域 20×20。

### 5.4 卡片

- 白底、1px `--line`、`--r-lg`、`0 1px 2px rgba(10,10,9,.06)` 极轻投影。
- 每个视图最多 **1 张墨黑锚点卡**（数据卡或主输入区），用于建立明暗节奏；不要把所有卡片都做成白的，也不要超过 1 张。
- hover：边框变 `--line-strong`，背景 `#FCFBF7`，150ms。
- 可点击卡片必须有明确的 focus ring：`0 0 0 2px var(--ink), 0 0 0 4px var(--paper)`。

### 5.5 设备框

- 外框 6px `#1A1A1A`，圆角 44；屏幕圆角 38；内阴影模拟玻璃边缘。
- 灵动岛：宽 92、高 26、圆角 14、纯黑。
- 状态栏：9:41、信号/WiFi/电池，10px。
- 底部 Home indicator：宽 120、高 4、圆角 2。

### 5.6 设计库卡片

- 图片区 9:16（移动）或 16:10（Web），`object-fit: cover`。
- 元信息两行：App 名（13/600）+ 界面名（11/mono/muted）。
- hover：图片轻微 `scale(1.02)`，底部浮出「应用」按钮。
- 不显示点赞数、浏览量等虚荣指标。

### 5.7 状态与反馈

- **Loading**：不用全屏 spinner；用局部骨架 + 逐字流。
- **空状态**：一句解释 + 一个主操作 + 一个示例。
- **Toast**：底部居中，墨黑底，纸白字，4s 自动消失；最多同时 1 个。
- **错误**：说明「发生了什么 / 你可以做什么」，不显示堆栈。

### 6.2 工作室

- 顶栏 56。
- 左栏 264（可折叠），右栏 368（可折叠），中间自适应。
- 画布最小宽度 640；窗口 < 1200 时右栏变为抽屉。
- 底部状态栏 28。

- 顶部 sticky：标题 + 搜索 + 筛选 chips。
- 网格：≥1440 为 5 列；1200 为 4 列；< 900 为 2 列。
- 卡片间距 20 / 24。

## 7. 动效

| 场景 | 参数 |
|---|---|
| hover / 按压 | 120–160ms，ease-out |
| 面板展开 | 220ms，`cubic-bezier(.2,.8,.2,1)` |
| 页面切换 | 180ms，opacity + 4px translate |
| Agent 流式输出 | 逐字 12–20ms/字；光标闪烁 1s |
| 生成完成 | 画布 0.98→1，220ms spring；不弹跳 |
| Toast | 进入 200ms 上移 8px；退出 150ms |
| 设备切换 | 240ms 宽度/圆角过渡 |

**减少动效**：尊重 `prefers-reduced-motion`，关闭位移与缩放，只保留透明度。

---

## 8. 图标

- 1.5px 线宽，24×24 视框，圆头圆角。
- 功能图标统一线性；品牌/模型用色块 + 字母。
- 不用 emoji 作为功能图标；营销页可用少量符号（→、↗、⌘）。
- 图标与文字间距 6–8px。

---

## 9. 文案规范

- 中文为主，英文术语保留原样（Prompt、Token、TestFlight）。
- 按钮用动词：生成、应用、构建、预览、导出；不用「确定」。
- 数字用等宽；金额保留两位小数；时间用相对时间（12 秒前）。
- 模型名不翻译，但首次出现可加中文说明。
- 错误信息三段式：**发生了什么** → **为什么** → **下一步**。

---

## 10. 可访问性

- 所有可交互元素有可见 focus ring。
- 点击区域 ≥ 44×44（移动端）。
- 正文对比度 ≥ 4.5:1；大字 ≥ 3:1。
- 不靠颜色单独传达状态，配合图标/文字。
- 键盘可达：Tab 顺序合理；⌘K 打开命令面板；Esc 关闭浮层。
- 动效可关闭；流式输出提供「跳过动画」。

## 11. 设计检查清单（交付前）

- [ ] 每个视图只有一个主按钮？
- [ ] 是否使用了真实界面作为视觉主角，而不是装饰性渐变？
- [ ] 模型色是否只出现在圆点/小标签？
- [ ] 所有数字是否等宽？
- [ ] 空状态是否有下一步？
- [ ] 深色画布上的文字对比度是否足够？
- [ ] 1200px 宽度下是否仍然可用？
- [ ] 键盘能否完成核心流程？
- [ ] 是否有不必要的阴影、圆角或渐变？
- [ ] 文案是否具体、可验证，而非形容词堆砌？
