02 / THREE GATES

三道闸：管住钱、管住上线、管住资格

交易里的闸不是审批流程，而是三种硬约束——过不去就停，不讨论。

GATE 01

风险闸 · 钱

每一笔订单在发出前，都要过一遍单笔、单策略、组合三级校验。过不去就拒单，不讨论。

  • 单笔风险 ≤ 权益 0.25%（按止损距离折算）
  • 单笔 ≤ 1% 价格带内挂单量的 5%
  • 同相关性簇 ≤ 40% 敞口
  • 止损由系统执行，人不参与
GATE 02

上线闸 · 钱能不能进来

策略写完不等于能实盘。必须先证明它在"没见过的数据"上成立，再证明它在"真实的成交"上成立。

  • 回测 ≥ 2 年，含牛熊各一轮
  • 样本外 ≥ 30%，成本按悲观口径
  • 纸面 4 周，偏差 < 25%
  • 金丝雀 1% 资金，4 周达标才扩仓
GATE 03

合规闸 · 证

这一层不是法律免责声明，是工程配置：密钥权限、资金分布、辖区资格，全都要能被审计。

  • API Key 禁止提币，绑定 IP 白名单
  • 单所资金 ≤ 50%，盈利定期提出
  • 不代客理财、不承诺收益、不喊单
  • 辖区合法是前置条件，不是选项

07 / WHAT KILLS YOU

会杀死你的八件事

这七条里的任何一条，都比"信号不够聪明"更常见。

01

过拟合

试了 500 组参数挑出最好的一组。用 deflated Sharpe、保留样本外、限制试验次数。

02

前视偏差

用了当时还拿不到的数据：资金费、收盘价、上币公告。回测必须 point-in-time。

03

交易所风险

宕机、插针、强平引擎异常、提币暂停。FTX 不是黑天鹅，是常态风险。

04

流动性幻觉

回测按中间价成交，实盘打穿三层盘口。单笔不得超过盘口深度的 5%。

05

杠杆与伪分散

以为分散了，其实四个仓位都在赌同一个方向。按相关性簇计算敞口。

06

运维事故

密钥泄露、重复下单、断线后状态不一致。幂等 ID + 对账 + 死手开关。

07

监管与身份

辖区不允许、代客无牌照、税务未申报。合法是前置条件，不是上线后再补。

08

AI 自我感动

把"模型很复杂"当成"策略有优势"。复杂度不是 alpha，成本才是敌人。

验收标准不是"赚了多少"，
而是"最坏的那天，系统有没有按设计停下来"。

如果你要把它做成产品：卖工具，不卖收益。碰客户资金、代客下单、收益承诺，是三件不同性质的牌照问题。
