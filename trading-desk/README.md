# 值班交易台 · TRADING DESK

一套面向 24 小时市场的交易运维流程：确定性执行、可量化的风险额度、一条走完才能上钱的资金阶梯。
一个单页原型 + 一份完整设计说明。

## 查看

双击 `index.html`。单文件、无依赖、无外链资源。

## 页面里能做什么

- **风险额度条**：日内亏损、名义敞口、保证金占用、单策略杠杆，四条红线与当前值
- **Kill Switch**：暂停新开仓 / 只减仓 / 全部平仓停机 / 恢复运行，点击后状态、提示与日志同步变化
- **资金阶梯**：研究 → 回测 → 纸面 → 金丝雀 1% → 实盘 10% → 淘汰
- **策略台账**：4 个策略的阶段、样本外夏普、回撤、容量
- **夜班日志**、**平台对照表**（Binance / OKX / IBKR / Alpaca）、**八种致命失败**

## 文件

- `index.html` — 单页原型（CSS / JS 内联）
- `DESIGN.md` — 完整设计：平台选型、七层架构、三道闸数值、资金阶梯、机会来源、AI 边界、成本预算、90 天落地、合规红线
- `PRODUCTION.md` — 实盘上线清单：八类 P0 检查项、放行标准、Go/No-Go 会议、上线后 30 天规则

## 说明

概念设计原型，与 Binance、OKX、IBKR、Alpaca 均无关联。页面数据均为演示，不构成投资建议。
文中所有收益、夏普、回撤均为设计目标口径，不是承诺。
