# 物理 AI 2056 — 未来三十年，智能走出屏幕

一份关于物理 AI 的长期研究型概念站。以 **2026—2056** 为观察跨度，梳理物理 AI 从验证、规模化、通用化到基础设施化的五个阶段，以及芯片、本体、基础模型、感知、仿真、场景六层产业链上的代表性企业与机会窗口，并从风险投资视角补充全球资本地图、资本周期与组合框架。

## 查看

直接双击 `index.html` 即可，无需安装、无构建步骤。

若浏览器限制本地文件加载，可在当前目录运行：

```bash
python -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 页面结构

- `index.html` — 单页结构：首屏、判断、时间轴、采用曲线、产业链、机会窗口、资本全景、三种 2056 情景、风险、结语
- `styles.css` — 视觉系统、响应式布局、动效
- `app.js` — 交互与数据可视化
- `assets/favicon.svg` — 站点图标

## 可交互内容

- 首屏 Canvas 点云人形：随指针扰动、扫描线与呼吸节点
- 三十年时间轴：点击节点或使用方向键切换五个阶段
- 采用曲线：悬停查看年份与渗透率，附完整数据表；移动端自动切换为条形摘要
- 产业链六层 Tab：切换查看各层代表企业、价值池与观察指标
- 「你的坐标」入口：一键跳转到对应产业链层
- 机会筛选：按近期 / 中期 / 远期窗口过滤九个方向
- 资本时钟：切换四个资本周期，配置示意条形同步更新
- 全球资本地图：六个地理枢纽，悬停区域卡片高亮对应节点
- 组合仓位：核心 / 成长 / 平台 / 期权四类资产的区间示意
- 三种情景：切换审慎 / 基准 / 激进，数字、前提与三条曲线同步更新；移动端同步高亮对应条形
- 风险手风琴、移动端导航、滚动进度与显现动画

## 口径说明

企业数据来自公开报道、公司披露与机构口径（截至 2026 年 10 月），包括 Omdia、国金证券、头豹研究院、MarketsandMarkets 等。2035 年出货量参考高盛 2026 年 9 月上调后的预测；2050 年人形机器人市场情景参考摩根士丹利长期研究。

页面中的长期规模、渗透率、价值池结构、资本时钟配置、组合仓位与三种 2056 情景均为编辑部情景推演，用于呈现分歧与假设，**不是预测，也不构成投资建议**。

## 设计说明

视觉方向为「工业研究档案」：墨黑底色、骨白文字、信号橙强调，衬线中文标题搭配等宽标签。所有图像由 CSS / SVG / Canvas 本地生成，无外部图片依赖；Google Fonts 加载失败时回退到系统中文字体。已适配 `prefers-reduced-motion`。
