05 METHOD & LIMITS / 观察方法

所有数字，
都应该能被追问。

这是一个观察站，不是策略超市。没有收益排行、没有跟单入口、没有「必胜参数」。下面写清楚每个数字从哪里来，以及它不能证明什么。

LAST AUDITED / 2026-10-31
01

社区热度

GITHUB REST API

星标、Fork、Issue 数与最近推送时间每 30 分钟尝试刷新一次，匿名 API 限额为每小时 60 次。刷新失败时保留最近一次快照，并在状态栏标记。

能证明

项目被多少人看见、是否仍在维护。

不能证明

策略收益、代码质量或实盘安全性。

02

发布下载

RELEASE ASSETS

累加每个仓库 GitHub Release 中二进制资产的 download_count。选择「下载」排序时，页面会按仓库重新汇总最近发布页资产，并缓存 6 小时。

能证明

有多少人下载了作者发布的安装包或二进制。

不能证明

pip、npm、源码克隆与容器拉取；GitHub 不公开仓库克隆数。

03

行情与费率

BINANCE / OKX

优先读取 Binance USDT-M Futures 公共接口：24h ticker、K 线、资金费率、持仓量与多空账户比。接口不可达时切换 OKX，仍失败则显示本地快照。

能证明

某一时刻的公开市场状态与持仓结构。

不能证明

未来价格方向；公开多空比也不等于主力仓位。

04

策略适配

LOCAL HEURISTIC

用 EMA20/60 距离、区间动量、ATR14、成交额与资金费率年化值，计算 5 类策略的 0—100 环境分。公式完全在前端执行，可展开查看。

能证明

当前环境更接近哪类策略的典型假设。

不能证明

策略胜率、回撤或收益；分数没有经过历史 alpha 检验。
