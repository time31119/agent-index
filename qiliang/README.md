# 起量 QILIANG · 成品网站

给大量中小业主的自动化营销短视频 AI 工具。**会员制软件，商家自己操作，平台只提供软件服务。**

## 网站结构

| 文件 | 用途 | 对外 |
|---|---|---|
| `index.html` | 官网首页：产品、模板、App、价格、FAQ、登录 | ✅ |
| `app.html` | 网页工作台：工作台 / 创作 / 发布 / 数据 | ✅ |
| `mobile.html` | 移动端 App：首页 / 创作 / 发布 / 数据 / 我的 | ✅ |
| `landing.css` / `landing.js` | 官网样式与交互 | ✅ |
| `minimal.css` / `minimal.js` | 网页工作台样式与交互 | ✅ |
| `mobile.css` / `mobile.js` | 移动端 App 样式与交互 | ✅ |
| `blueprint.html` | 内部产品蓝图 | ❌ 不要发给商家 |

对外交付只发 **`index.html` + `app.html` + `mobile.html` + 三套 CSS / JS + `favicon.svg` + `manifest.webmanifest`**。`blueprint.html` 是内部文档。

## 官网首页

- 一句话价值：**不会拍，也能持续有视频。**
- 三步说明：说一句 → 选模板 → 发布
- 4 个核心能力：一句话出脚本 / 5 个镜头自动补 / 3 种声音配音 / 三平台适配
- 产品界面预览
- 3 个模板
- 3 类用户：本地生活 / 电商带货 / 服务门店
- 会员价格：免费 / ¥699 月 / ¥6,710 年
- FAQ、登录弹层、移动端导航

## 工作台

4 个页面：

1. **工作台**：一句话输入 + 4 个目标 + 3 个模板 + 3 条进行中 + 3 个本月数字。
2. **创作**：大预览 + 4 步（脚本 / 画面 / 配音 / 成片）。
3. **发布**：3 个账号、2 条待发布、时间、AI 标识、推流预算。
4. **数据**：3 个大数字、平台贡献、3 条内容、1 条建议。

侧栏只有 4 个导航，会员入口在侧栏底部。设置里有「返回官网」。

## 移动端 App

`mobile.html` 是一套独立设计的移动端 App：

- 5 个底部导航：首页 / 发布 / 创作 / 数据 / 我的
- 首页：一句话输入、模板横滑、进行中、本月数字
- 创作：预览 + 脚本 / 画面 / 配音 / 成片
- 发布：3 个账号、待发布、时间、AI 标识、推流预算
- 数据：3 个大数字、平台贡献、下一条建议
- 我的：会员卡、平台账号、网页版入口、返回官网
- 会员与发布用底部 Sheet，不跳页
- 桌面打开是手机框预览；手机打开自动全屏
- 带 `manifest.webmanifest`，可当作 PWA 安装到桌面

官网的「App」区块和 Footer 都可以进入 `mobile.html`。

## 设计原则

- **一屏一任务**：每页一个主按钮。
- **字先于密度**：正文 17px、按钮 16px、标签不低于 13px；不用 7–9px 小字。
- **颜色少**：纸、墨、朱红、成功绿；不用黄色小字，不用低对比组合。
- **操作先于学习**：蓝图、拆解、平台长文不进主界面。
- **只卖软件**：不做代运营、拍摄、设计外包。
- **平台状态诚实**：抖音 API 直发；视频号 / 小红书半自动，不做 RPA。
