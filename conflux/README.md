# 合流 Conflux — 机器人与 AI 产品 · 网站概念原型 v0.1

> 好项目不该缺钱，好创意不该缺人。

面向机器人与 AI 产品团队的融资 / 合伙撮合平台，首页与项目详情页的可交互高保真原型。

## 怎么看

直接用浏览器打开 `index.html`，无需构建、无外部依赖、不需要联网（字体走系统字体栈）。

- 建议桌面端 1440px 宽度浏览，再缩到手机宽度看响应式表现
- 首页：`index.html`
- 项目详情：`project.html`（从首页任一项目卡片进入）

## 文件结构

```
conflux/
├─ index.html          首页（10 个模块）
├─ project.html        项目详情页（7 个区块 + 侧栏）
└─ assets/
   ├─ styles.css       设计系统与全部样式
   └─ app.js           交互层（无依赖）
```

## 这一版包含什么

**品牌与视觉系统**

- 色板：墨蓝 `#0B1B2B` / 象牙 `#F6F2EA` / 鎏金 `#C6A15B` / 松绿 `#2F7D5D`
- 字体：正文系统无衬线（PingFang / 微软雅黑），数字等宽对齐，英文用字距拉开
- 组件：按钮、标签、指标行、进度环、验证分、里程碑轴、数据室行、匿名意向条

**首页模块**

1. Hero：主叙事 + 实时项目卡（TRL / 融资进度 / 匿名意向 / 里程碑状态）
2. 生态合作条（示意）
3. 三入口：找资金 / 找创意资金 / 找合伙人
4. 精选项目 + 赛道筛选
5. 四道验证关卡
6. 里程碑托管（30 / 40 / 30）
7. 四层信任基建
8. 合伙人三角模型（90 天试婚期）
9. 客户证言
10. 合规底线 + 入驻表单

**项目详情页**

概览 / 技术与验证（TRL 1–9）/ 市场与订单 / 团队 / 融资方案 / 数据室 / 问答，右侧为约谈与匿名意向操作区。

**交互**

赛道筛选、数字滚动、进度环、滚动揭示、吸顶导航、移动端菜单、约谈时段选择、表单校验与 Toast 提示。

## 几个设计决策

1. **不用插画，用图纸。** Hero 背景是一张抽象的工程图（同心圆、十字基准线、刻度），比机器人插画更克制，也更符合“技术资产”的语境。
2. **中文标题用黑体而非宋体。** 宋体在本机常回退到 SimSun，大字号下会显得陈旧；改用无衬线 + 负字距 + 大字号，更接近精品投行的气质。
3. **信息密度刻意偏高。** 投资人看项目是“扫”不是“读”。卡片里直接给 TRL、专利数、验证分、融资进度，减少点击成本。
4. **金色只用在“证据”和“钱”上。** 验证分、进度、里程碑、关键 CTA。其余保持墨蓝与象牙的克制。
5. **所有数据均为虚构。** 页脚已注明，避免被误读为真实业绩。
