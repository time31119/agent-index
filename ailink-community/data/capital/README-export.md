# 资金库导出接入说明

## 支持平台

- 清科数据 / 私募通（投资界）
- IT 桔子
- 睿兽分析
- 企查查 / 天眼查（工商字段）

## 导出字段

优先按以下字段导出，列名不一致也可以，导入时会做映射：

| 字段 | 必填 | 说明 |
|---|---|---|
| 机构名称 | 是 | 投资机构/基金/ CVC |
| 机构类型 | 否 | VC/PE/CVC/政府基金/母基金/FA |
| 城市 | 是 | 杭州/深圳优先 |
| 省份 | 否 | 浙江/广东 |
| 区域 | 否 | 华东/华南/华北/西南 |
| 成立年份 | 否 | 机构成立时间 |
| 管理规模 | 否 | AUM |
| 单笔金额 | 否 | 单笔投资区间 |
| 投资阶段 | 否 | 天使/Pre-A/A/B/C/PE |
| 关注赛道 | 否 | AI/具身智能/半导体/医疗 AI 等 |
| 投资人姓名 | 否 | 合伙人/投资总监/CVC 负责人 |
| 职位 | 否 | 合伙人/董事总经理/投资总监 |
| 邮箱 | 否 | 商务邮箱；没有就留空 |
| 电话 | 否 | 机构总机/商务电话 |
| 地址 | 否 | 办公地址 |
| 官网 | 否 | 机构官网 |
| 来源 | 是 | 清科/IT桔子/睿兽/企查查 |
| 数据日期 | 是 | 导出日期 |

## 导出后放哪里

```text
ailink-community/data/raw/
```

建议文件名：

```text
capital-qingke-2026-11.csv
capital-itjuzi-2026-11.csv
capital-ruishou-2026-11.csv
capital-qcc-2026-11.csv
```

## 导入规则

1. 机构去重：名称 + 城市
2. 人员去重：姓名 + 机构
3. 邮箱/电话保留原始值，不强行补全
4. 缺城市/缺机构名的行进入待核验
5. 只导出公开商务联系方式，不导入个人手机/私人微信
6. 每条记录保留来源和导出日期

## 安全

不要把账号密码、短信验证码发到对话里。  
只提供导出的 CSV/Excel 或 API Key；导入后不保留原始账号凭据。
