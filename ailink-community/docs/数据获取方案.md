# AILink 智链 · 数据获取方案

> 版本：v1.0（2026-11-05）  
> 适用范围：项目库、资金库、人才库；第一阶段华东 / 华南，第二阶段全国。  
> 结论先行：**不做“全网爬虫 + 买卖个人联系方式”的生意。走“授权数据 + 公开企业信息 + 社区共建”三轨制，先把 2,000 条可用数据做扎实。**

---

## 一、先给结论：五条定夺

### 1. 不追求“所有”，先追求“可用”

“杭州、深圳所有 AI 企业”“全国所有投资人”“全国所有 AI 人才”在商业上不成立：

- 企业边界是动态的：今天做 AI 应用，明天可能转型；分子公司、工作室、项目组是否算一家，没有统一口径。
- 投资主体是动态的：机构在募新基金、合伙人离职、FA 与个人天使交织，工商信息无法完整表达“谁在真正出手”。
- 人才更不可能“全”：大量候选人被动看机会，不愿公开姓名与联系方式。

所以第一阶段的目标不是“全”，而是：

> **2,000 条项目 + 300 个资金方 + 1,000 位人才；联系方式核验率 ≥ 60%；核心字段完整率 ≥ 85%；每周更新。**

这 2,000 条能支持 100–300 位付费会员完成真实对接，比 20 万条脏数据更有价值。

### 2. 三轨制，不把命运押在单一来源

| 轨道 | 占比目标 | 内容 | 获取方式 |
| --- | --- | --- | --- |
| A. 授权 / 采购 | 40% | 工商、融资事件、企业联系方式、部分决策人信息 | 数据服务商 API、企业版账号、数据处理协议 |
| B. 公开信息 | 35% | 官网、园区名录、协会名录、融资公告、专利、论文、活动议程 | 合规采集 + 人工整理，遵守 robots 与平台条款 |
| C. 社区共建 | 25% | 会员认领、活动报名、人才主动登记、推荐与纠错 | 明示同意、激励与审核 |

### 3. 联系方式分层，个人手机与微信必须“有依据”

- **L1 企业公开联系方式**：官网商务邮箱、总机、公开商务合作微信 —— 可收录，标注来源。
- **L2 决策人工作联系方式**：创始人 / 投资人的工作邮箱、名片、活动报名信息 —— 需有合法来源：本人提供、活动报名同意、授权数据商、商业伙伴转介。
- **L3 人才个人联系方式**：手机、微信、简历 —— **只做 opt-in**，候选人主动登记并同意被会员检索。
- **绝不碰**：来源不明的数据包、爬取简历、绕过登录墙、猜测 / 拼接邮箱、私人手机号批量导入。

### 4. 人才库只做 opt-in

人才数据是最敏感的。建议把人才库做成“AI 人才社区”，而不是“简历库”：

- 候选人自己创建档案，选择“公开 / 匿名 / 仅被邀约”；
- 联系方式默认隐藏，候选人接受邀约后才解锁；
- 会员看到的是“方向、年限、技能、期望、可谈机会”，而不是身份证式的履历；
- 候选人可随时撤回、更正、删除。

这会让早期数据量小一些，但能避免最大的一类合规风险，也更容易获得高质量候选人。

### 5. 先做 8 周，再谈全国

- **Phase 0（2 周）**：字段、去重、核验、合规模板。
- **Phase 1（6 周）**：杭州 + 深圳打穿，扩到上海、广州、南京、苏州、厦门、东莞；2,000 / 300 / 1,000。
- **Phase 2（12 周）**：北京、成都、武汉、西安、合肥等，10,000 / 1,000 / 5,000。
- **Phase 3（6 个月后）**：30,000+ / 3,000+ / 20,000+，周级更新，开放 API。

## 二、先定义“什么算一条可用数据”

### 2.1 项目库纳入标准

满足以下任意两条，进入候选池：

1. 主营业务包含 AI 技术或 AI 产品（大模型、Agent、AI Infra、具身智能、智能驾驶、AI 芯片、AI 医疗、AIGC、工业视觉、数据智能等）；
2. 有至少 3 人的 AI 研发 / 算法团队；
3. 近 24 个月有 AI 相关融资、专利、软著或公开产品；
4. 位于目标城市的 AI 园区、孵化器、协会名录；
5. 有可验证的 AI 产品收入或客户案例。

排除：只“使用 AI”的传统公司、壳公司、无实际经营团队、纯培训 / 咨询（可单列服务商库）。

### 2.2 资金库纳入标准

- 机构：有明确投资主体、官网或公开备案、近 36 个月有出手记录；
- 个人天使：有公开投资案例或会员推荐，本人同意被收录；
- FA：单列类型，不与投资机构混排；
- 政府基金 / CVC：标注类型与决策链，避免会员误判。

### 2.3 人才库纳入标准

- 主动登记，或明确授权公开；
- 3 年以上 AI 相关经验，或博士 / 核心项目经历；
- 至少一项可验证的技能 / 项目 / 论文 / 专利；
- 同意被会员检索，并可随时撤回。

### 2.4 质量分（0–100）

| 维度 | 权重 | 说明 |
| --- | --- | --- |
| 完整性 | 25 | 必填字段缺失数量 |
| 可核验性 | 25 | 官网 / 工商 / 人工电话核验 |
| 新鲜度 | 20 | 最近 90 天 / 180 天 / 365 天 |
| 可联系性 | 20 | 邮箱有效、电话可通、退信率 |
| 来源可信度 | 10 | 官方 / 授权 API / 社区登记 / 二手转述 |

低于 60 分不进主库，只在后台“待核验池”；连续两次退信自动降级。

## 三、数据来源：三轨制拆解

### 3.1 A 轨：授权 / 采购（40%）

#### 企业工商与知识产权

- **来源**：国家企业信用信息公示系统、企查查企业版、天眼查企业版、爱企查。
- **字段**：企业名称、统一社会信用代码、注册地址、成立时间、参保人数、专利、软著、经营范围、股东。
- **方式**：优先 API；没有 API 的字段用企业版账号人工查询，保留查询记录。
- **成本**：约 3–15 万元 / 年，取决于调用量与字段。
- **注意**：工商信息中的联系人常是代办 / 财务，不可直接当作业务联系人。

#### 融资事件与机构数据

- **来源**：IT 桔子、企名片、CVSource、机构官网、交易所公告、36 氪 / 投资界等公开报道。
- **字段**：融资时间、轮次、金额、投资方、FA、估值（如有）。
- **方式**：API / 数据包 + 人工核对；同一事件至少两个来源交叉。
- **成本**：约 2–10 万元 / 年。
- **注意**：融资新闻存在“官宣口径”和“实际到账”差异，金额标注“披露口径”。

#### 企业联系方式与决策人

- **来源**：探迹、励销云等企业数据服务商；部分厂商提供“企业总机 + 部门负责人”数据。
- **方式**：采购前要求提供数据来源说明、授权链、更新频率、退订机制；签数据处理协议（DPA）。
- **成本**：约 1–5 万元 / 年 / 席位，或按条计费。
- **注意**：不要买“个人手机号包”；不要用来源不明的“老板通讯录”。

### 3.2 B 轨：公开信息（35%）

#### 企业官网 / 产品页

- 提取：一句话介绍、产品、客户案例、商务邮箱、总机、地址。
- 方式：人工整理 + 合规采集（遵守 robots，不绕过登录 / 付费墙）。
- 价值：官网的商务邮箱通常比工商电话更可用。

#### 园区 / 政府 / 协会名录

- 杭州未来科技城、深圳南山、上海张江、苏州工业园区、广州琶洲、厦门软件园等。
- 方式：官网公开名录、园区合作、协会会员名单。
- 价值：园区名录是“AI 企业宇宙”的最高质量起点之一。
- 注意：部分名录有版权 / 使用限制，合作前确认。

#### 融资公告 / 专利 / 论文 / GitHub

- 融资公告：补全投资方与轮次；
- 专利 / 论文：判断技术方向与团队；
- GitHub：判断开源项目与工程能力。
- 方式：官方 API、公开检索；保留链接。

#### 活动议程 / 公开演讲

- Demo Day、行业峰会、路演、闭门会嘉宾名单。
- 价值：能拿到“谁在做什么、谁在投什么”的一手信息。
- 注意：活动名单的使用范围以报名页授权为准。

### 3.3 C 轨：社区共建（25%）

#### 会员认领

- 企业 / 机构 / 人才可以认领自己的档案，补充联系方式、融资、招聘需求。
- 激励：认领后获得免费曝光、活动优先、额度奖励。
- 审核：企业认领需验证域名邮箱或营业执照；人才认领需验证手机 / 邮箱。

#### 活动报名

- 报名表单独勾选：
  - “愿意被 AILink 会员发现并联系”；
  - “愿意接收 AI 创业社区的活动与融资信息”。
- 两个勾选分开，不能默认勾选，不能捆绑。

#### 推荐与纠错

- 会员推荐同行、投资人、候选人；
- 发现错误可一键纠错，运营 48 小时内处理；
- 推荐奖励：邮件额度、会员天数、活动门票。

#### 内容共创

- 联合发布《杭州 AI 创业地图》《深圳具身智能生态报告》；
- 通过榜单 / 报告收集企业主动报名；
- 注意：榜单需有明确口径，避免“付费排名”误导。

## 四、联系方式怎么拿：分层 SOP

### 4.1 企业公开总机 / 商务邮箱

1. 从官网 / 园区名录 / 企业版数据库获取；
2. 用企业邮箱域名做 MX 记录检查；
3. 记录来源 URL、抓取 / 整理时间、核验人；
4. 标注“企业公开”，不标注“决策人直联”。

### 4.2 决策人工作邮箱

优先级从高到低：

1. 本人主动提供（活动报名、会员认领、名片）；
2. 商业伙伴转介（需转介人确认）；
3. 授权数据服务商（需 DPA 与来源说明）；
4. 公开演讲 / 论文 / 官网团队页上的工作邮箱；
5. **不做**：姓名 + 域名猜测、买通讯录、爬取个人社交账号。

### 4.3 电话核验

- 企业总机：工作时间拨打，确认公司仍在运营、联系人是否在职；
- 决策人电话：首次触达以短信 / 邮件预约为主，不 cold call 骚扰；
- 每次核验记录：时间、接听人、结果、下次跟进；
- 空号 / 停机 / 拒接 2 次 → 降级。

### 4.4 邮箱核验

- 语法 + 域名 MX +  disposable 域名库；
- 可选 SMTP 探活（注意频率与合规，不要对个人邮箱做轰炸式验证）；
- 首次发送用小流量测试，监控退信率；
- 退信 > 5% 的域名暂停发送，先修数据。

### 4.5 人才联系方式

- 只从本人登记表 / 授权页面获取；
- 默认“隐藏”，候选人接受邀约后才向该会员展示；
- 会员查看需记录访问日志；
- 候选人可一键隐藏 / 删除。

## 五、数据 Schema（最小可用版）

### 5.1 项目库

```text
id, name, city, district, province, region,
sector[], stage, founded_year, team_size,
funding_total, latest_round, latest_amount, valuation,
description, highlights[], website, products[],
contact_name, contact_title, phone, email, wechat,
source_type, source_url, source_note,
verified, confidence, last_verified_at, updated_at,
owner, status
```

### 5.2 资金库

```text
id, name, type, city, province, region,
focus[], stages[], ticket_min, ticket_max,
aum, fund_currency, portfolio[],
contact_name, contact_title, phone, email, wechat,
website, source_type, source_url,
verified, confidence, last_verified_at, updated_at
```

### 5.3 人才库

```text
id, display_name, anonymous, role, city, region,
years, current_company, education, skills[],
availability, expected_salary, open_to[],
summary, phone, email, wechat, linkedin,
consent_scope, consent_at, source_type,
verified, confidence, last_verified_at, updated_at
```

### 5.4 必备的“元数据”

每条记录都必须有：

- 来源类型（官方 / 授权 API / 公开页面 / 会员登记 / 推荐）；
- 来源链接或凭证；
- 授权方式（如适用）；
- 最近核验时间；
- 核验人 / 核验方式；
- 可信度分；
- 删除 / 撤回标记。

没有这些元数据的数据，不允许进入会员可见的主库。

## 六、工具栈

### 6.1 采集与清洗

| 工具 | 用途 | 备注 |
| --- | --- | --- |
| Playwright | 公开页面渲染、表单流程 | 只采公开页面，遵守 robots |
| Scrapy | 结构化站点批量采集 | 加限速、重试、UA 标识 |
| Apify | 快速验证采集流程 | 注意 Actor 的来源与条款 |
| 八爪鱼 | 运营同学做简单采集 | 适合一次性名录，不适合长期 |
| Python + pandas | 清洗、标准化、去重 | 最灵活 |
| Splink / dedupe | 实体消歧 | 统一社会信用代码优先 |

### 6.2 数据服务

| 类型 | 工具 / 供应商 | 用途 |
| --- | --- | --- |
| 工商 / 知识产权 | 企查查、天眼查、爱企查、国家企业信用信息公示系统 | 企业主体、股东、专利 |
| 融资事件 | IT 桔子、企名片、CVSource | 轮次、金额、投资方 |
| 企业联系方式 | 探迹、励销云 | 企业总机、部门联系人 |
| 地图 / 地址 | 高德开放平台、腾讯位置服务 | 地址标准化、园区坐标 |
| 邮箱验证 | ZeroBounce、NeverBounce、MillionVerifier | 降低退信 |
| 域名 / MX | 自建脚本 + DNS 查询 | 基础校验 |

### 6.3 存储与检索

| 工具 | 用途 |
| --- | --- |
| PostgreSQL / Supabase | 主数据、会员、额度账本 |
| Meilisearch / Elasticsearch | 全文检索、筛选、拼音 |
| Redis | 缓存、频控、队列 |
| S3 / OSS | CSV、合同、附件 |
| dbt / Great Expectations | 数据转换与质量测试 |
| Metabase | 数据质量与运营看板 |

### 6.4 自动化与触达

| 工具 | 用途 |
| --- | --- |
| n8n / Airflow / Prefect | 定时抓取、清洗、核验任务 |
| 阿里云邮件推送 / 腾讯云 SES | 国内发信 |
| SendGrid / Mailgun / Resend | 海外发信 |
| 企业微信 / 飞书 | 运营通知、会员服务 |
| HubSpot / 纷享销客 / 销售易 | CRM、跟进 |
| PostHog / Umami | 产品分析 |
| Sentry | 错误监控 |

### 6.5 最小组合（2 周内跑通）

- 表格：飞书多维表格 / Airtable（先跑流程）
- 采集：Playwright + Python
- 清洗：pandas + 自写去重
- 验证：DNS MX + 人工电话
- 存储：PostgreSQL（Supabase）
- 检索：Meilisearch
- 发信：阿里云邮件推送（先 20 封测试）
- 自动化：n8n
- CRM：飞书 / HubSpot 免费版

## 七、自动化流水线（SOP）

### Step 1 发现

- 输入：园区名录 URL、协会名单、融资事件、活动报名、会员推荐。
- 输出：候选实体（名称 + 城市 + 来源）。
- 质量控制：每条候选必须有来源链接；同一来源去重。

### Step 2 结构化

- 统一城市 / 区域 / 赛道 / 阶段字典；
- 企业名称清洗（去掉“有限公司”后缀做匹配，但保留全称）；
- 地址标准化（高德 / 腾讯地图）；
- 融资币种、金额单位统一为人民币万元。

### Step 3 去重

优先级：

1. 统一社会信用代码完全匹配；
2. 企业名称 + 城市 + 法人 / 电话匹配；
3. 名称相似度 + 地址相似度；
4. 人工复核边界案例。

人才去重：邮箱 / 手机 / 姓名 + 当前公司；同一人多个邮箱合并。

### Step 4 核验

- 机器：域名 MX、邮箱语法、电话格式、地址存在性、官网可访问；
- 人工：电话抽检、官网联系人页核对、融资事件交叉；
- 记录：核验方式、时间、人、结果；
- 抽样：每周随机 10% 复核，错误率 > 3% 触发停线。

### Step 5 更新

- 周级：新增融资、官网变更、退信 / 退订；
- 月度：联系方式抽检、园区名录增量；
- 季度：全量字段体检、失效标记；
- 触发式：会员纠错、企业认领、候选人更新。

### Step 6 发布

- 主库（会员可见）只放质量分 ≥ 60 的记录；
- 待核验池只在后台；
- 每次发布生成版本号与变更日志；
- 删除 / 撤回请求 48 小时内生效。

## 八、分阶段路线图

### Phase 0：2 周，定标准

| 周 | 任务 | 产出 |
| --- | --- | --- |
| W1 | 字段字典、去重规则、质量分、合规模板 | Schema v0.9、CSV 模板、隐私政策框架 |
| W2 | 100 条种子数据、10 个会员访谈、供应商询价 | 种子库、需求清单、2 家数据商报价 |

**退出标准**：字段无歧义；每条数据有来源；能跑通一次“筛选 → 导出 → 发信 → 回复”。

### Phase 1：6 周，华东 + 华南

## 十、合规与邮件触达

### 10.1 法律底线

- 《个人信息保护法》：合法、正当、必要、诚信；告知目的与方式；最小必要；可撤回、可删除。
- 《数据安全法》《网络安全法》：数据分级、访问控制、日志审计、泄露预案。
- 《互联网电子邮件服务管理办法》：商业邮件需事先同意、真实发件人、退订方式。
- 《反不正当竞争法》：不得以技术手段抓取他人非公开数据、不得侵犯商业秘密。
- 《刑法》第 253 条之一：侵犯公民个人信息罪，买卖、提供、非法获取都可能触线。

> “公开信息”不等于“可以无限使用”。公开的企业信息也要受目的限制、版权与平台条款约束；公开的个人信息同样受《个人信息保护法》约束。

### 10.2 合规动作清单

- [ ] 隐私政策、会员协议、数据处理协议（DPA）；
- [ ] 每类数据源记录合法性依据与授权链；
- [ ] 人才库单独同意，展示范围可选；
- [ ] 退订、删除、更正入口；
- [ ] 会员访问日志与导出审计；
- [ ] 供应商尽调：来源、授权、更新频率、删除能力；
- [ ] 员工培训与违规处理；
- [ ] ICP 备案 / 等保（正式上线）；
- [ ] 数据出境评估（如有海外用户 / 数据）。

### 10.3 邮件触达规则

- 只向有合法联系依据的对象发送；
- 主题真实，不伪装回复、不伪造发件人；
- 每封含一键退订；
- 频控：同一收件人 30 天内 ≤ 2 封；
- 退信率 > 5% 暂停域名；投诉率 > 0.1% 停发整改；
- 发信域名独立，配置 SPF / DKIM / DMARC；
- 新域名预热 2–4 周，从每天 50 封起步；
- 不使用购买的收件人列表；
- 邮件内容遵守《广告法》，不做虚假承诺。

### 11.1 供给端（先把数据做厚）

1. **园区合作**：未来科技城、南山、张江、苏州工业园区、琶洲、厦门软件园；用“免费园区专场”换名录与活动。

4. **活动**：闭门会、Demo Day、训练营；报名表就是最好的数据入口。
5. **会员认领**：企业 / 机构 / 人才认领档案，送曝光与额度。

### 11.2 需求端（让会员愿意付费）

- SEO / 内容：《杭州 AI 公司地图》《深圳具身智能 50 家》《AI 投资人名单（授权版）》；
- 免费工具：AI 公司查询、融资事件日历、邮件模板；
- 活动：闭门融资对接、人才见面会；
- 转介绍：会员推荐会员，双方各得额度；
- 数据报告：季度《华东 AI 创业生态报告》。

### 11.3 数据飞轮

```text
更多会员 → 更多认领 / 纠错 / 推荐 → 数据更准
→ 更好的匹配与触达 → 更多成功案例 → 更多会员
```

关键指标不是“数据量”，而是：

- 会员 7 日内是否完成第一次有效搜索；
- 是否导出 / 收藏 / 发信；
- 是否产生真实对接（回复、会议、投资）；
- 数据纠错率与退信率。
