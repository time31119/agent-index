# AILink 智链 · AI 创业社区

一个面向 AI 创业者、投资人与核心人才的社区型数据平台原型：**项目库 + 资金库 + 人才库 + 会员订阅 + AI 邮件引擎**。

首站覆盖杭州、深圳，并向华东 / 华南扩展；产品路线图再逐步连接全国。当前站点是一个**可直接运行的前端产品原型**，支付、发信与第三方登录均为模拟流程。杭州、深圳各 42 家企业来自公开资料图谱，其余城市与企业为虚构演示样本。

> 杭州 AI 核心企业总量为公开报道的 **938 家**；深圳官方口径为 **2,600+ 家 AI 典型企业**，2026 年目标超 **3,000 家**。本库在双城各接入 **42 家代表企业**，并明确标注覆盖率，不把“代表样本”说成“全量名录”。

## 快速开始

### 方式一：直接打开

双击 `index.html` 即可。所有数据、路由和交互都在浏览器本地运行。

### 方式二：本地服务器（推荐）

```bash
# 需要 Node.js 18+
node serve.mjs

# 或
npm run dev
```

打开 `http://127.0.0.1:4173`。

也可以用 Python：

```bash
python -m http.server 4173
```

## 数据说明

数据分两层：

**A. 杭州 42 家 + 深圳 42 家 AI 核心企业（公开资料）**

- 杭州来自 `hangzhou-ai-atlas` 公开信息图谱；深圳来自公开官网与公开报道整理；
- 保留企业名称、官网、分类、城区、成立年份、状态、业务描述与公开来源；
- 原数据**没有电话 / 邮箱**，因此本库不编造，统一标记“联系方式待核验”，仅展示官网入口；
- 42 家是结构性代表样本，不是全量名录；页面显示杭州 42 / 938、深圳 42 / 2,600+ 的覆盖率。
- 杭州 938 为公开报道口径（[JST Science Portal China](https://spap.jst.go.jp/china/news/260902/topic_5_01.html)）；深圳 2,600+ 为深圳市发改委 2026-02-10 公开口径（[来源](https://fgw.sz.gov.cn/gkmlpt/content/12/12639/post_12639574.html)）。均不是本库自采数据；全量名录需园区 / 工商授权数据补全。

**B. 其他城市与企业、机构、人才（虚构演示）**

- 邮箱统一使用 `example.com` 保留域名；
- 电话使用不可路由的占位号码；
- 企业与人物名称如有雷同，纯属巧合。

这样做的原因：真实个人手机号 / 邮箱 / 简历属于个人信息，不能在未授权的情况下批量采集、编造或售卖。正式上线应接入**授权数据源 + 公开企业信息 + 会员主动登记**，并记录来源、授权方式与核验时间。详见 [`docs/数据获取方案.md`](docs/数据获取方案.md)。

## 生产化之前必须替换的部分

1. **认证**：接入手机号 / 邮箱验证码、微信登录或企业 SSO；服务端 session。
2. **会员与支付**：微信支付 / 支付宝 / 对公转账，服务端订单、回调验签、幂等与发票。
3. **数据**：PostgreSQL + 对象存储 + 搜索引擎；字段级权限；来源与核验日志；删除 / 撤回通道。
4. **邮件**：服务端队列（BullMQ / SQS）、发信域名 SPF/DKIM/DMARC、退订列表、Webhook、退信处理。
5. **AI**：服务端调用大模型 API，加入品牌语气、敏感词与事实校验；不要在前端暴露密钥。
6. **合规**：隐私政策、会员协议、数据处理协议、等保 / ICP 备案、数据出境评估（如适用）。
7. **运营**：数据认领、纠错、推荐奖励、周级更新与质量看板。

详见 [`docs/产品与技术架构.md`](docs/产品与技术架构.md)。
