先说出你要去哪
例如：去王府井
设置（高德 Key / 语音 / GPS）

填了 Key 会调用高德地理编码与步行路线；失败会自动回退到演示路线。 Key 只存在你本机浏览器。

怎么玩

  1. 先点一个演示目的地（或按住麦克风说“去王府井”）
  2. 点“开始导航”，它会用语音报出第一段路线
  3. 箭头和文字会随“模拟前进”实时变化，走完会提示到达
  4. 勾选“使用真实 GPS”后，它会跟着你真实位置走（需要授权）

说明：这是交互原型，路线为演示数据；语音识别需要 Chrome / Edge，并在 http://localhost 或 HTTPS 下才能用麦克风。 没有高德 Key 也能完整体验——用的是内置的模拟路线。
