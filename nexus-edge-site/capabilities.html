VALUE CHAIN · 4 STAGES

一条把想法变成商品的
流水线。

硬件创业最贵的不是零件，是「来回试错」的时间。我们把产品化拆成四段，每段有交付物、有验收标准、有报价—— 你可以在任何一段插入，也可以整条交给我们。

01

设计 Design

从场景反推产品：先定义用户动作、成本上限与认证边界，再决定芯片、结构与交互。我们坚持「先算清 BOM 和良率，再画第一根线」，避免做出漂亮但卖不动的样机。

交付物
  • 产品需求文档（PRD）与竞品拆解
  • ID 效果图、结构 3D 与手板建议
  • 原理图、PCB、天线与 EMC 预布局
  • BOM 成本表（含双供替代方案）
  • 认证路径预研（SRRC / CE / FCC / CCC）
周期2–4 周
团队产品 + 硬件 + 结构
验收方案评审通过
费用可抵扣后续开发
02

开发 Develop

ESP-IDF 组件化固件：配网、OTA、低功耗、日志、故障自恢复全部沉在平台层，场景代码只占两成。App / 小程序 / 云端同步开工，避免「硬件等软件」的经典拖延。

交付物
  • 可编译固件仓库与版本管理（含 CI）
  • Matter / MQTT / BLE 协议对接
  • App 或小程序（iOS / Android / 微信）
  • 设备云：设备管理、OTA 灰度、看板
  • 产测工装与自动化测试脚本
周期4–8 周
团队嵌入式 + 云端 + 前端
验收全链路演示通过
迭代每两周一个可测版本
03

整合 Integrate

把样机变成能出货的商品：双供应链、SMT 与组装、老化与抽检、射频与安规认证、包装与说明书。这一段的唯一 KPI 是良率与一致性，而不是功能多少。

交付物
  • 可量产 BOM 与双供定点清单
  • 工艺文件、SOP、测试夹具
  • SRRC / CE / FCC / RoHS 证书
  • 老化与抽检报告（含不良分析）
  • 包装、说明书、合规标识
周期6–10 周
团队供应链 + 品质 + 工厂
验收小批良率 ≥ 98%
起订500–1000 台起
04

品牌化销售 Brand & Sales

产品只有被记住才能溢价。命名、视觉、包装、评测内容、众筹与渠道政策一起设计；售后与固件订阅，把一次性交易变成长期关系。这一段决定你是「代工厂」还是「品牌」。

交付物
  • 品牌命名、视觉识别与包装设计
  • 产品页、详情页、评测样机与视频
  • 渠道政策（自营 / 亚马逊 / 经销 / 集成商）
  • 售后体系：备件、返修、FAQ、工单
  • 订阅方案：云服务、模型更新、增值功能
周期持续
团队品牌 + 销售 + 客服
验收首批出货与复购
目标复购率 > 25%
BUSINESS MODEL

三条收入曲线，互相供养。

只做代工会被压价，只做品牌会缺现金流。健康的结构是：定制项目养活团队，标品建立品牌，订阅沉淀资产。

CURVE 01 / 现金流

ODM 与方案定制

为客户做整机或模块定制，收开发费 + 量产差价。回款快、风险低，同时把每一单的非标需求沉淀成平台模块。

行业毛利参考30–45%
CURVE 02 / 品牌

自有品牌标品

在 2–3 个品类里做「看一眼就懂」的爆款：统一的 ID 语言、开箱即用的体验、可讲的故事。这是品牌资产的真正载体。

行业毛利参考45–60%
CURVE 03 / 复利

平台与订阅

设备云、OTA、AI 模型更新、行业数据服务。一次开发、长期收费，客户越多边际成本越低——这是估值故事的核心。

行业毛利参考70%+

注：毛利区间为硬件行业常见参考值，随品类、批量与渠道差异较大，不作为承诺。

HOW WE WORK

六个节点，
把不确定性关进笼子。

D0需求评审

60 分钟会议，输出可行性判断：能不能做、大概多少钱、多久、风险在哪。不收费。

W1报价与排期

拆解工作包，给出固定报价或「开发费 + 量产差价」两种模式，明确知识产权归属。

W2–4方案与打样

原理图 / PCB / 结构冻结，出 3–5 台功能样机，确认关键器件与认证路径。

W5–8联调与小批

固件、App、云端联调；50–100 台试产，验证工艺与良率，修正 DFM 问题。

W9–14认证与量产

SRRC / CE / FCC 送检，同步准备包装与说明书；首批量产并交付。

持续运维与迭代

OTA 升级、故障分析、成本优化（VA/VE），每季度一次产品复盘。
