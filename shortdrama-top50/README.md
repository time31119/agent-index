# 短剧全球流量榜 · TOP 50

一个零依赖的静态站点，盘点 2026 年 11 月仍在运营的 50 个全球短剧平台，按「流量指数」排序，并把口径、置信度和数据源全部写在页面上。

> 范围：面向成年观众的**剧情类短剧 App**。不含露骨成人内容平台，不含长视频平台的短剧频道，不含纯网文/音频产品（Pocket FM 因已做视频短剧而例外收录并标注）。

## 打开方式

直接双击 `index.html` 即可，无需构建、无需联网、无外部字体与 CDN 依赖。

若想用本地服务器预览：

```bash
python -m http.server 8765 --directory .
# 打开 http://127.0.0.1:8765
```

## 流量指数怎么算

```
指数 = 70 × D + 20 × R + 10 × C

D = log10(月下载) 在 [0.15M, 40M] 上的归一化
R = log10(月流水) 在 [0.05M, 50M] 上的归一化
C = 在榜市场数 / 41
```

- 下载权重最高，因为「流量」首先指用户规模；
- 流水用来区分「有量但不赚钱」的免费平台，IAA 的流水含广告收入，已与 IAP 分开标注；
- 市场数只做轻微修正，避免印度、东南亚等单区域平台被系统性低估或高估。

页面上的分数由 `app.js` 实时计算，改动 `data.js` 里的 `downloads` / `revenue` / `coverage` 后刷新即可重排。

## 数据字段（`data.js`）

| 字段 | 说明 |
| --- | --- |
| `name` / `company` / `hq` | 平台名、运营方、总部 |
| `launch` | 上线年份 |
| `model` | `IAP` 内购 / `IAA` 广告 / `IAAP` 混合 |
| `camp` | 中国出海 / 海外本土 / 南亚本土 |
| `markets` / `coverage` | 主战场标签、在榜市场数（0–41） |
| `downloads` | 估算月下载，百万次（双端） |
| `revenue` | 估算月流水，百万美元 |
| `confidence` | 高 / 中 / 低，判定规则见页面「方法论」 |
| `blurb` / `evidence` | 一句话判断、数据依据 |

## 平台入口（`SD_LINKS`）

`data.js` 末尾的 `window.SD_LINKS` 以平台名为键，存三类链接：

| 字段 | 说明 |
| --- | --- |
| `site` | 官方站点，2026-11-02 逐一抓取校验（标题/站点名与平台一致才收录） |
| `ios` | App Store 正式页 |
| `android` | Google Play 正式页 |

- 榜单行内的 ↗ 指向「官网 → App Store → Google Play」中第一个可用者；展开详情里三个入口全部列出。
- 没有 `site` 的平台多为纯 App 产品，或官网会拦截自动抓取（如 Cloudflare/CloudFront 403），因此优先给商店正式页。
- 商店链接取自 Short Drama Data 各 App 资料页的公开按钮，未做二次人工核对，如发现指错请附链接更正。

## 已知局限

- 没有任何第三方能给出全球短剧 App 的真实 UV/MAU，本榜是公开信号的**合成估算**，不是实测流量。
- 付费榜与免费榜的分数不可直接横比（Short Drama Data 自己的口径说明也如此），本站用下载量做共同标尺来缓解。
- 同一集团的多品牌按独立 App 计入，集团层面的集中度高于榜单直观感受。
- 30–50 名区间的绝对值误差最大，只适合判断梯队。
