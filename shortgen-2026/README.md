# SHORT/GEN 2026 — 短视频生成器索引

把 2026 年 11 月的短视频生成器选型清单，做成一个可直接打开的静态网站。

- **33 款工具**，按出片链路分四层：视频模型 / 一站式成片 / 图文口播 / 剪辑数字人
- 每款工具都有价格、规格、适合谁、注意什么
- 8 款主力模型的横向对比表
- 一个按「可用片」计算的成本计算器
- 4 个场景选型 + 6 步工作流
- 暗色 / 亮色主题、搜索、筛选、排序、详情弹窗、深链

## 打开方式

直接双击 `index.html` 即可（纯静态，无构建、无依赖、无外部字体/接口）。

想用本地服务器：

```bash
# 任选其一，在项目目录执行
python -m http.server 8080
npx serve .
```

然后访问 `http://localhost:8080`。

> 通过 `file://` 打开也完全可用，脚本均为普通 `<script>`，没有 fetch / ES module 的跨域限制。

## 交互说明

| 操作 | 效果 |
|---|---|
| 顶部搜索 / 工具库筛选框 | 按名称、厂商、能力、标签实时筛选，两处输入同步 |
| 快捷标签（30 秒直出 / 4K / 开源…） | 一键筛选并滚动到工具库 |
| 分类 Tab | 全部 / 视频模型 / 一站式成片 / 图文口播 / 剪辑数字人 |
| 排序 | 推荐 / 评分最高 / 最新发布 |
| 点击卡片 | 打开详情：完整描述、规格、价格、适合谁、注意点、官网/搜索入口 |
| 成本计算器 | 选模型、画质档、时长、抽卡次数、通过率，实时算「每条可用片」成本 |
| 主题按钮 | 暗色 / 亮色切换，写入 localStorage |
| `/` | 聚焦搜索框 |
| `Esc` | 关闭弹窗 |
| `?open=kling-40` | 直接打开某款工具的详情（可分享的深链） |
| `?theme=light` | 以亮色主题打开 |

## 改数据

所有内容都在 `assets/data.js` 的 `window.SITE_DATA` 里，不需要懂构建。

### 新增一款工具

在 `tools` 数组里加一项：

```js
{
  id: "my-tool",                 // 唯一，用于深链与弹窗
  name: "工具名", en: "Tool Name",
  vendor: "厂商", cat: "model",  // model | agent | script | edit
  rating: 4.5, badge: "标签",
  released: "2026-10-01",
  tagline: "一句话卖点",
  desc: "两到三句完整描述。",
  chips: ["4–30s", "4K", "原生音频"],
  specs: [{ k: "单次时长", v: "4–30 秒" }],
  price: "¥x–y / 秒", priceNote: "计费口径",
  bestFor: "适合谁", caution: "注意什么",
  url: "https://example.com",    // 可省略；省略时弹窗显示「搜索官网」
  tags: ["4K", "低价"]           // 参与搜索
}
```

分类计数、Tab 数字、搜索索引都会自动更新。

### 调整对比表

`compare` 数组，一行一款模型，字段与表格列对应。

### 调整计算器

`calc` 数组，`tiers` 是画质档与「元/秒」单价：

```js
{ id: "my-tool", name: "工具名", tiers: [{ label: "1080p", price: 6.48 }] }
```

`id` 与 `tools` 中的 id 对应即可复用名称。

### 改主题色

`assets/style.css` 顶部 `:root`：

```css
--accent: #ff5a2b;   /* 主色 */
--accent-2: #ffb03a; /* 渐变第二色 */
--bg: #07080c;       /* 背景 */
```

亮色主题在 `[data-theme="light"]` 中覆盖。

## 设计说明

- 深色底 + 暖橙主色，靠层级、细线和等宽小字建立「索引 / 数据」气质，而不是堆卡片阴影。
- 中文标题使用系统黑体（PingFang / 微软雅黑），英文与数字使用等宽字体，形成编辑感。
- 所有内容单页呈现，移动端单列，Tab 与筛选自动换行。
- 动效只用于入场与悬浮，支持 `prefers-reduced-motion`。
- 无外部字体、无 CDN、无追踪代码。

## 数据口径

- 价格为 2026 年 10–11 月的公开挂牌价或测评实付价，美元按 1:7.2 粗算。
- 模型迭代很快，价格与能力以官网为准。
- 主要来源见页面页脚「数据来源」，包括 ByteDance Seed、界面新闻、新浪财经、c114/SuperCLUE、南方都市报、钛媒体、阿里云百炼等。
- 本站为独立整理，非商业榜单；外链指向官网或搜索结果。
