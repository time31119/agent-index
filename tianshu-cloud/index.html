import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://token.quanxiyun.cloud/v1",
  apiKey: process.env.TIANSHU_API_KEY,
});

const stream = await client.chat.completions.create({
  model: "glm-5.3",
  messages: [{ role: "user", content: "你好，天枢云" }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? "");
}

FAQ

常见问题

天枢云与上游平台是什么关系？
天枢云是面向客户的品牌与服务入口，底层的模型算力、账号体系与计费账单由上游合作平台提供。 你在天枢云看到的模型目录、价格与调用地址，与上游控制台保持同步。
已有 OpenAI 代码，需要改多少？
只需要两处：把 base_url 指向 https://token.quanxiyun.cloud/v1，把 api_key 换成天枢云控制台创建的密钥。 请求体、返回格式与流式行为保持一致，模型名替换为目录中的 id 即可。
支持哪些客户端和框架？
任何兼容 OpenAI 协议的工具都可以接入，包括 Cherry Studio、Lobe Chat、OpenCat、AionUI、AI as Workspace、CC Switch， 以及 LangChain、LlamaIndex、Dify、n8n 等编排框架。
如何充值与开票？
注册后进入控制台，在「钱包 / 充值」中选择金额，支持在线充值，支付方式以收银台为准；发票可在控制台提交申请。 企业采购与对公转账请通过 联系我们 沟通。
价格和模型官网不一致，以哪个为准？
天枢云展示的是官方基准价折算，实际扣费会叠加实时渠道折扣与汇率，可能低于展示价。 所有价格以控制台「模型价格」页与每笔调用账单为准。
调用失败或响应变慢怎么办？
平台对同一模型配置了多条上游线路，会按健康度自动切换。若持续异常，请在控制台查看调用日志中的错误码， 并联系技术支持；企业客户可获得专属对接群。
