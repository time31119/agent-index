开发文档

天枢云提供与 OpenAI 完全兼容的 HTTP 接口。保留现有 SDK，替换地址与密钥即可完成迁移。

概览

天枢云是一个统一的模型调用网关。所有请求都发往同一个域名，通过请求体中的 model 字段选择具体模型；鉴权、计费、日志与线路切换都在网关侧完成。

Base URL
https://token.quanxiyun.cloud/v1
协议
HTTPS · JSON · SSE（流式）
鉴权
Authorization: Bearer sk-...
兼容
OpenAI Chat Completions / Images / Embeddings
方法路径说明
POST/v1/chat/completions对话补全，支持流式与工具调用
GET/v1/models获取当前账号可用模型列表
POST/v1/images/generations图像生成
POST/v1/embeddings文本向量化
POST/v1/video/generations创建视频生成任务
GET/v1/video/generations/{task_id}查询视频任务状态与结果
天枢云负责品牌、客户服务与技术支持；模型算力、账号与账单由上游合作平台承载。 本文档描述的是双方共同使用的接口规范，参数与返回与你在上游控制台看到的一致。

快速开始

整个接入过程只有三步：注册账号、创建密钥、修改 Base URL。

  • 在 注册页 完成账号注册并登录控制台。
  • 进入「令牌 / API Key」页面创建一个密钥，复制以 sk- 开头的字符串。
  • 把你的 SDK 的 base_url 改为 https://token.quanxiyun.cloud/v1，模型名改为目录中的 id。
export TIANSHU_API_KEY="sk-ts-你的密钥"

curl https://token.quanxiyun.cloud/v1/chat/completions \
  -H "Authorization: Bearer $TIANSHU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5.3",
    "messages": [{"role": "user", "content": "你好"}]
  }'
from openai import OpenAI

client = OpenAI(
    base_url="https://token.quanxiyun.cloud/v1",
    api_key="sk-ts-你的密钥",
)

completion = client.chat.completions.create(
    model="glm-5.3",
    messages=[{"role": "user", "content": "你好"}],
)
print(completion.choices[0].message.content)
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://token.quanxiyun.cloud/v1",
  apiKey: process.env.TIANSHU_API_KEY,
});

const res = await client.chat.completions.create({
  model: "glm-5.3",
  messages: [{ role: "user", content: "你好" }],
});
console.log(res.choices[0].message.content);

鉴权方式

所有请求都需要在 HTTP Header 中携带密钥：

HTTP Header 
Authorization: Bearer sk-ts-xxxxxxxxxxxxxxxx
Content-Type: application/json
  • 密钥只在创建时完整显示一次，请妥善保存，不要提交到公开仓库。
  • 建议按项目或环境分别创建密钥，便于统计用量与快速吊销。
  • 如怀疑泄露，请立即在控制台删除并重新生成。

对话补全

标准 OpenAI Chat Completions 接口，支持系统提示词、多轮对话、工具调用与结构化输出参数。

POST /v1/chat/completions

{
  "model": "qwen3.8-max",
  "messages": [
    {"role": "system", "content": "你是一名严谨的技术顾问"},
    {"role": "user", "content": "用三句话解释什么是 API 网关"}
  ],
  "temperature": 0.7,
  "max_tokens": 1024
}
{
  "id": "chatcmpl-8f2c...",
  "object": "chat.completion",
  "created": 1786000000,
  "model": "qwen3.8-max",
  "choices": [{
    "index": 0,
    "message": {"role": "assistant", "content": "..."},
    "finish_reason": "stop"
  }],
  "usage": {
    "prompt_tokens": 42,
    "completion_tokens": 128,
    "total_tokens": 170
  }
}
计费以响应中的 usage 为准。开启流式时，usage 会在最后一个 chunk 返回； 部分客户端会自动丢弃该字段，建议以控制台账单核对实际用量。

流式输出

在请求体中设置 "stream": true，服务端会以 SSE 逐块返回增量内容。

Python · 流式 
stream = client.chat.completions.create(
    model="deepseek-v4.1-flash",
    messages=[{"role": "user", "content": "写一段产品介绍"}],
    stream=True,
)

for chunk in stream:
    delta = chunk.choices[0].delta
    if delta.content:
        print(delta.content, end="")

图像生成

使用标准 Images 接口，模型名从 模型广场 的图像分类中选择。

POST /v1/images/generations 
curl https://token.quanxiyun.cloud/v1/images/generations \
  -H "Authorization: Bearer $TIANSHU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen-image-3.0-pro",
    "prompt": "极简风格的科技品牌主视觉，深蓝背景，发光几何体",
    "size": "1024x1024",
    "n": 1
  }'

响应中的 data[].url 为图片地址，部分模型也会返回 b64_json。图片地址存在有效期，建议及时转存。

视频生成

视频属于异步任务：先创建任务，再轮询任务状态获取成片地址。

POST /v1/video/generations

{
  "model": "seedance-2.0",
  "prompt": "镜头从海面推近到灯塔，黄昏，电影感",
  "duration": 5,
  "images": ["https://example.com/reference.jpg"],
  "metadata": {
    "resolution": "720p",
    "ratio": "16:9"
  }
}
GET /v1/video/generations/{task_id}

{
  "id": "task_abc123",
  "object": "video.generation",
  "status": "completed",
  "progress": 100,
  "output": {
    "video_url": "https://cdn.example.com/output/task_abc123.mp4"
  }
}

status 取值：queued（排队）、in_progress（生成中）、completed（成功）、failed（失败）。建议轮询间隔 5–10 秒。

向量化

POST /v1/embeddings 
{
  "model": "text-embedding-3-large",
  "input": ["第一段文本", "第二段文本"]
}

客户端接入

任何支持自定义 OpenAI 接口地址的客户端都可以直接使用，配置时填写以下三项：

  • API 地址 / Base URL：https://token.quanxiyun.cloud/v1
  • API Key：控制台创建的 sk- 密钥
  • 模型：模型广场中的 id，例如 glm-5.3

已验证可用的客户端包括 Cherry Studio、Lobe Chat、OpenCat、AionUI、AI as Workspace、CC Switch 等； LangChain、LlamaIndex、Dify、n8n 等框架按 OpenAI Provider 配置即可。

错误码

HTTP含义处理建议
400请求参数错误检查 JSON 结构、模型名与必填字段
401鉴权失败确认密钥正确、未被删除、Header 格式为 Bearer
403无权限或额度不足检查账户余额、模型分组与实名认证状态
404模型不存在核对模型 id，或先调用 /v1/models 查询
429请求过于频繁指数退避重试，或联系商务提升配额
500上游服务异常稍后重试；持续出现请联系技术支持
503暂无可用线路等待自动切换或更换其他模型

错误响应遵循 OpenAI 格式：{"error": {"message": "...", "type": "...", "code": "..."}}。

限流与配额

  • 默认并发与每分钟请求数（RPM）由账号等级与模型决定，可在控制台查看当前配额。
  • 单个密钥可设置额度上限，避免误用或密钥泄露造成超额消费。
  • 视频、图像等异步任务有独立的任务队列并发限制。
  • 需要更高配额或专属线路，请通过 联系我们 沟通。
