## 1. 项目背景与目标

上游供应商为 `token.quanxiyun.cloud`（对外名称 TOTAL RHINO CLOUD），是一家 AI 模型 API 聚合分发平台，提供文本、图像、视频与多模态模型的统一调用能力。

我们要做的不是复制一个上游，而是建立一个**独立品牌的客户入口**：

- 有自己的品牌名、Logo、公司主体与域名；
- 模型目录、接口协议、计费口径与上游保持一致（核心内容不变）；
- 注册、登录、充值、开票等交易动作**链接到上游平台**完成；
- 客户在我们这里获得品牌化的介绍、文档与技术支持。

一句话定位：**上游提供算力与结算，我们提供品牌、入口与服务。**

### 2.2 Logo

**构成**：旋转 45° 的圆角方框 + 内环轨 + 中心光点 + 右上角青色节点。

- 方框 = 接口边界与稳定感；
- 环轨 = 请求在多家上游之间的路由与流转；
- 中心光点 = 每一次调用；
- 右上节点 = 持续接入的新模型。

**色彩**：品牌渐变 `#9DB4FF → #6C8CFF → #35E0C8`，底色 `#06080F`。

**文件**：

| 文件 | 用途 |
| --- | --- |
| `assets/img/logo-mark.svg` | 主图形标（站内 34px、社媒头像） |
| `assets/img/logo-lockup.svg` | 横版锁合标（PPT、合同、名片） |
| `assets/img/favicon.svg` | 浏览器图标 |
| `assets/img/og-cover.svg` | 社交分享封面（1200×630） |

**使用规范**：

- 图形标最小尺寸 24px，横版锁合最小宽度 120px；
- 清空区不小于中心光点直径的 2 倍；
- 深色底使用彩色渐变版；浅色底需另做深色单色版（`#0B1220`）；
- 禁止拉伸、加描边、加投影、替换渐变色，禁止与上游 Logo 并排组合成"联合品牌"。

> 生产环境建议将 `logo-lockup.svg` 中的文字转为轮廓（outline），避免字体缺失。

## 4. 核心内容如何"保持不变"

| 维度 | 处理方式 |
| --- | --- |
| 模型 | 模型 ID 与上游完全一致（如 `glm-5.3`、`kimi-k3`、`seedance-2.0`），可直接复制调用 |
| 接口 | Base URL `https://token.quanxiyun.cloud/v1`，OpenAI 兼容，端点与参数不变 |
| 计费 | 按 Token / 按张 / 按秒；输入输出分开计价；展示官方基准价折算 |
| 价格口径 | 官方倍率 × 2 USD/百万 tokens × 6.82 汇率；实际扣费叠加实时渠道折扣 |
| 规则 | 实名认证、充值方式、发票、失败不计费等规则与上游一致 |
| 客户端 | Cherry Studio、Lobe Chat、OpenCat、AionUI、AI as Workspace、CC Switch 等 |

**改写而非搬运**：所有页面文案为原创，未复制上游页面结构、图片与公司信息；价格表基于其公开定价接口计算，并标注快照日期与"以控制台为准"。

## 6. 技术方案

- **形态**：纯静态站点（HTML + CSS + 原生 JS），无构建步骤、无第三方依赖、无外部字体与统计脚本。
- **部署**：阿里云 OSS + CDN（或 Vercel / Cloudflare Pages）。国内访问建议 OSS + 备案域名。
- **性能**：首屏资源 < 100KB；无阻塞脚本；图片仅 3 个 SVG。
- **SEO**：每页独立 title / description / OG；上线时把 `og:image` 换成绝对地址与 PNG（部分平台不解析 SVG）。
- **可访问性**：跳转链接、语义化标签、可见焦点样式、`prefers-reduced-motion` 适配。
- **兼容性**：`file://` 直接双击即可预览；无需服务器。

**目录**：

```
tianshu-cloud/
├── index.html / models.html / pricing.html / docs.html / partners.html / about.html
├── assets/css/main.css
├── assets/js/models-data.js   # 模型与价格数据（改这一个文件即可更新目录）
├── assets/js/app.js           # 导航、筛选、复制、滚动动效
└── assets/img/*.svg
```

> 更新模型时只改 `models-data.js`；价格表 `pricing.html` 为静态表格，需同步修改（后续可改为脚本渲染）。

## 7. 合规清单（上线前逐项确认）

1. **公司注册**：杭州主体，经营范围建议包含"技术服务、技术开发、软件开发、互联网信息服务、信息技术咨询"。
2. **域名**：完成实名认证；建议同时注册 `.com` 与 `.cn`。
3. **ICP 备案**：通过云服务商提交至浙江省通信管理局，通常 7–20 个工作日；备案号替换页脚占位。
4. **公安联网备案**：网站上线后 30 日内完成。
5. **经营性许可**：如以自有主体向前端客户收费并提供在线服务，可能涉及增值电信业务经营许可（B25 信息服务业务），建议咨询专业机构后再定模式。
6. **生成式 AI 合规**：上游持有相应资质（增值电信业务经营许可证 B1.B2‑20262219）；我们作为品牌与服务入口，须在页面显著位置说明服务由上游提供，避免用户误认服务主体。若未来独立面向公众提供生成式 AI 服务，需按规定履行备案/登记义务。
7. **协议与隐私**：上线《用户协议》《隐私政策》《充值退款说明》，并与实际经营主体一致。
8. **内容安全**：明示禁止生成违法与侵权内容；建立投诉与处置通道。
9. **广告法**：避免"最""第一""国家级"等绝对化用语（现有文案已规避）。
10. **发票主体**：开票主体、合同主体、收款主体保持一致。

> 以上为产品与建站视角的清单，不构成法律意见；正式上线前请由法务或专业机构复核。

## 10. 代理商模式（渠道体系）

**目标**：用较低获客成本覆盖区域、行业与开发者社群，把一次性客户变成持续分发的渠道。

### 10.1 四级体系

| 等级 | 准入门槛（近 3 个月月均有效充值） | 佣金 | 差异化权益 |
| --- | --- | --- | --- |
| L1 推广伙伴 | 0（实名即可） | 10% | 专属链接 / 邀请码、佣金看板、基础物料 |
| L2 认证代理 | ≥ ¥3,000 | 15% | 95 折优惠码、1v1 支持、联合方案 |
| L3 金牌代理 | ≥ ¥20,000 | 20% | 92 折码、客户经理、优先线路、2% 市场基金 |
| L4 城市 / 行业代理 | ≥ ¥80,000 或年框 ¥300,000 | 25% | 区域独家、白标站、联合投标、年度返点 |

佣金按客户实付充值额计算，扣除退款、赠送与优惠券成本；等级次月生效，降级有 1 个月缓冲。

### 10.2 结算与归属

- 月结，次月 10 日出单，满 ¥500 提现，T+7 到账；
- 客户首次绑定后 12 个月内充值均计佣，活跃客户自动续期；
- 企业开票、个人代扣；退款从当期佣金扣回；
- 撞单以系统首次绑定为准；自充值、关联账号等套佣行为不计佣。

### 10.3 白标（OEM）

独立域名 + Logo + 定价 + 专属 API 网关，7–10 天上线，适合有客户资源但不想从零建站的团队。
本次交付的站点本身即可作为白标模板复用。

### 10.4 网站落点

- 新增 `partners.html`：等级、收益测算器、权益、结算规则、白标、申请流程、FAQ；
- 首页新增渠道合作横幅，全站导航与页脚加入「渠道合作」；
- 申请入口指向控制台「分销中心」，企业合作走 business@ 邮箱。

### 10.5 上线前必须复核

- 佣金率与「市场基金」需按真实毛利与上游结算规则测算，避免倒贴；
- 与上游确认分销归属、结算周期与提现规则能否支撑本站承诺；
- 明确个人代理的税务与发票处理方式；
- 渠道协议模板需法务审核（独家区域、撞单、违约）。
