About

关于天枢云

我们相信，模型会越来越多，但接入方式应该越来越简单。天枢云做的，就是那个稳定的「枢纽」。

名字的由来

「天枢」是北斗七星的第一颗，古人视其为天之枢纽，众星绕之而行。 我们把品牌取名为天枢云，是希望它成为一个稳定、可信的连接点——让不同厂商、不同模态的模型， 都通过同一个入口被调用。

标识由旋转 45° 的圆角方框、环轨与核心光点构成：外框是「接口与边界」，环轨是「路由与流转」， 中心的亮点是「每一次调用」。右上角的青色节点，代表不断接入的新模型。

我们做什么

天枢云是面向企业与开发者的 AI 模型 API 聚合网关。我们把多家模型厂商的文本、图像、 视频与多模态能力，收敛为一套 OpenAI 兼容接口，并提供统一的密钥管理、用量统计与技术支持。

你不需要分别注册多个平台、维护多套密钥，也不需要为每家厂商写一套适配代码。 改一个 base_url，换一个 model 名称， 业务就能在模型之间平滑迁移。

我们如何协作

天枢云负责品牌、客户服务、接入支持与账单解释；底层的模型算力、账号体系与计费执行， 由我们的上游合作平台提供。双方使用同一套接口规范，因此你在本站看到的文档、模型名与价格口径， 与上游控制台保持一致。

我们不做「黑盒中转」：每一次调用都可以在控制台查到用量与扣费明细， 价格调整也会通过公告同步，而不是悄悄发生。

我们正在做

  • 整理常见业务场景的接入模板，降低从 0 到 1 的成本。
  • 完善多线路健康检查与故障自动切换策略。
  • 为团队客户提供用量看板、预算提醒与月度对账单。
